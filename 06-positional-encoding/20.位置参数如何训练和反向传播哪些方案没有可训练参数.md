# 20. 位置参数如何训练和反向传播，哪些方案没有可训练参数？

## 可学习绝对表

若 \(h_i=x_i+P[position_i]\)，上游梯度对位置表行直接累加：

\[
\frac{\partial\mathcal L}{\partial P_p}
=\sum_{i:position_i=p}
\frac{\partial\mathcal L}{\partial h_i}.
\]

训练中常见位置收到更多更新，长位置若样本稀少则学习不足。Padding 若错误参与，会让某些位置吸收无意义梯度；需要 attention 和 label mask，而是否冻结 PAD 位置取决于实现。

## 相对 bias/向量

T5 风格每头 bucket bias 是可训练参数，同一 bucket 会聚合所有对应 token 对的梯度，远距离被压进同一 bucket 后共享统计。Shaw 相对 key/value 向量也可训练。它们的梯度量与距离分布高度相关，因此训练采样长度决定哪些 bucket 学得好。

固定正弦、标准 RoPE 与标准 ALiBi 通常没有通过梯度学习的位置参数：sin/cos 由公式生成，RoPE base/frequency 和 ALiBi slopes 多为超参数。尽管位置函数固定，梯度仍通过旋转/相加运算传回 Q/K 和上游网络；“无可训练参数”不等于位置机制不影响训练。

某些变体会让 RoPE 频率、缩放或 ALiBi slope 可学习。这样增加适应性，也可能出现频率塌缩、训练长度过拟合和部署配置依赖，需要约束及监控。

## 工程诊断

查看位置表每行梯度/更新范数与位置频次，能发现长位置没训练；对 bucket bias 画每头随距离的值；固定方案则监控 QK score 随相对距离和长度变化。若冻结主干只训练位置参数，容量有限，不能期待它单独赋予模型长程推理。

面试回答应按“绝对表、相对参数、固定函数”分类，给出查表梯度聚合公式，并说明固定 RoPE 仍可微地改变 Q/K 梯度。延伸追问是为什么只把 max_position 配大不会训练新位置，以及长序列采样如何影响远距参数。
