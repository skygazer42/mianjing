# 17. 长度外推和长度内插有什么区别，为什么训练长度很重要？

## 定义

长度外推是训练只见过位置/距离 \(0\ldots L\)，推理直接使用 \(L\) 之外的新位置；内插则把更长序列的位置映射到训练覆盖范围内，例如 RoPE 位置插值 \(p'=p/s\)。外推要求模型处理未见的索引、相位或距离；内插避免越出范围，却改变了位置分辨率和真实距离含义。

## 为什么公式可延伸仍不够

正弦、RoPE、ALiBi 都能在任意整数位置计算，但网络的 Q/K 投影、前馈层和 attention 模式只在训练长度分布上优化。训练中若从未要求跨越数千 token 找证据，模型可能只形成局部策略。长序列还改变干扰候选数、softmax 分母、文档结构和优化动态，因此位置函数只是长上下文能力的一部分。

可学习绝对表的外推问题最直观：新行没有训练。RoPE 直接外推会进入新的相位组合；位置插值把它压回旧范围，却让相邻角度差变小。ALiBi 的距离偏置可继续线性计算，但极远 token 被强烈惩罚。没有方案免费解决所有长度。

## 训练长度的两个维度

“最大长度”不等于“有效长样本”。如果绝大多数 batch 只有几百 token，偶尔 padding 到 32k，模型几乎没学到远距关系。需要统计有效 token 长度、依赖跨度和目标位置分布，并构造真正需要远端信息的样本。课程式从短到长训练可控成本，但最终必须覆盖部署目标。

## 评估方法

在多段长度上画性能曲线：训练内、边界附近、2×/4×；同时测 perplexity、局部任务、长文理解与合成检索，并改变目标深度和干扰项。若仅在固定模板 needle 测试通过，可能是模式匹配而非普遍长程推理。

面试回答应强调“外推看未见位置，内插改位置尺度”，再指出公式、训练数据和计算三者缺一不可。真正的上下文上限是质量与资源的经验边界，不只是配置里的 max_position_embeddings。
