# 07. padding、截断和 position_ids 之间是什么关系？

## 三者职责

Padding 把不同长度样本对齐到同一张量，attention mask 决定哪些位置有效；truncation 在超过上限时删除 token；position_ids 则告诉模型每个有效 token 使用哪个位置。三者必须按同一序列语义生成，但互不替代：给 PAD 一个位置 id 不等于屏蔽它，mask 正确也不能修复有效 token 的位置错号。

## 右填充与左填充

右填充样本 \([a,b,c,PAD,PAD]\) 常用有效位置 \([0,1,2]\)，PAD id 可填 0 或任意安全值，因为其注意力和 loss 应被屏蔽。左填充 \([PAD,PAD,a,b,c]\) 若直接用数组索引 \([0,1,2,3,4]\)，有效 token 变成 \([2,3,4]\)。某些绝对位置模型会因此让同一句在不同 batch 宽度得到不同输出。常见做法由 mask 累积：

\[
position\_ids=\operatorname{cumsum}(mask)-1,
\]

再把 PAD 位置填为安全值，使有效 token 始终从 0 开始。是否应这样做必须遵循模型训练约定。

## 截断语义

右截断保留前缀，位置仍从 0 开始；左截断保留原文后缀时，可以把它重新编号 0…L-1，也可保留全局原位置。对可学习绝对表通常只能重编号；对 RoPE/长文窗口，保留全局 offset 能维持跨窗口距离，但必须在训练和推理中一致。不能只看 tokenizer 输出长度而忽略窗口起点。

## 常见故障

全 PAD 行的 cumsum 会产生 -1，查表越界；需 clamp/填安全 id。Packed samples 若只拼 token 却不同时重置 mask 和 position，会跨样本泄漏。特殊 BOS 是否占 position 0、缓存前缀长度是否计入，也常导致 off-by-one。

面试回答应分别定义 padding mask、label mask 与 position_ids，并用左右 padding 例子说明。可靠测试是同一句单独编码和放进不同长度 batch 时输出应按模型约定一致。
