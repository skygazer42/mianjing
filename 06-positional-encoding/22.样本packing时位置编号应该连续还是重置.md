# 22. 样本 packing 时位置编号应该连续还是重置？

## 结论

把多个短样本拼到一条长张量能减少 padding，但 position_ids 是否重置没有唯一答案：若每段应被模型视为独立序列，通常同时使用 block-diagonal attention mask、重置每段位置并在 loss 边界正确屏蔽；若拼接本来就是连续文档，则位置应连续、允许跨段注意。关键是位置、attention 和监督边界表达同一语义。

## 独立样本 packing

设两段长度 3 和 2，token 拼成 \([A_0,A_1,A_2,B_0,B_1]\)。独立语义可用 position \([0,1,2,0,1]\)，并禁止 B 看到 A、A 看到 B。仅重置位置但仍用普通 causal mask，B 会读取 A，造成跨样本污染；仅做 block mask 但位置连续，则 B 从位置 3 开始，训练分布随前面无关样本长度变化。

标签也要处理边界：A 末尾不应被训练去预测 B 首 token，除非有显式 EOS 并且协议如此。常见做法将跨段 next-token label 设为 ignore，或为每段添加 EOS。

## 连续文档 packing

若块来自同一长文连续切片，跨块上下文有意义，连续位置更合理。若受最大长度/滑窗限制，需要记录全局 offset 或按模型训练方式重置。RoPE 可用全局 position 维持真实距离，但超出训练范围要配缩放；可学习绝对表则受上限约束。

## 性能与实现

Block-diagonal mask 若展开成稠密 \(L^2\) 会抵消 packing 收益，应使用支持 variable-length/segment 的高效 attention kernel。每个 token 需携带 segment id 或 cumulative sequence lengths，以便同时生成 mask 和 position。分布式重排必须保持三者同步。

## 面试要点

回答应先问“段之间是否允许通信”，再决定连续或重置；强调 position reset 不能替代 block mask，label 边界也不能遗漏。验证可把独立样本单独前向与 packed 前向对应 token 的 logits 比较，预期在数值容差内一致。
