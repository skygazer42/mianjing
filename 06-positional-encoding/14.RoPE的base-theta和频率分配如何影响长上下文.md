# 14. RoPE 的 base theta 和频率分配如何影响长上下文？

## 频率定义

RoPE 常为第 \(i\) 个二维对定义

\[
\omega_i=\theta_{\text{base}}^{-2i/d_r},
\qquad \phi_i(p)=p\omega_i.
\]

小 \(i\) 是高频，位置变化一点相位就明显；大 \(i\) 是低频，覆盖更长尺度。base theta 控制频率谱跨度。提高 base 通常让大部分非最高频通道旋转更慢，从而推迟长距离的相位变化，有利于更长上下文，但会改变模型训练时学到的距离模式。

## 为何不是简单“base 越大越好”

高频通道提供相邻 token、标点和局部语法的精细位置信号；频率整体过慢可能降低短距离分辨率。预训练权重已适应某组 \(\omega_i\)，推理时直接改 base 会让同一距离对应不同相位，属于分布迁移。某些扩展方法只调整部分频率或配合继续训练，正是在平衡局部分辨率与远距覆盖。

相位具有周期性，单个通道在 \(2\pi/\omega_i\) 后绕回；多频率联合能消歧，但超训练长度后相位组合仍可能进入未见区域。长上下文效果不仅由最低频周期决定，还受网络是否学会使用低频维、attention mask 和数据中长程依赖影响。

## 工程检查

配置项可能叫 rope_theta、rotary_emb_base 等；加载模型时必须以 checkpoint 配置为准。修改 base 后旧的 cos/sin cache 要重建，量化/编译模型也可能把常数固化。应在短长度回归集先确认质量没有明显下降，再测边界及更长长度，而不是只跑 needle 测试。

数值上，大 position 与高频 \(\omega\) 的乘法需要足够精度。若 position 先转 BF16，较大整数会失去单位分辨率，导致相邻位置角度相同；通常在 FP32 中构造角度和三角值。

面试回答应从频率公式解释 base 对快慢通道的影响，并强调它是短程分辨率、长程相位与 checkpoint 适配的折中，不是独立的“最大长度开关”。
