# 18. 二维图像和多模态序列如何设计位置编码？

## 二维位置

图像 patch 不只有一维先后，而有行列坐标 \((r,c)\)。最简单的方法是分别学习/计算 row embedding 与 column embedding 后相加：\(p_{r,c}=p_r^{row}+p_c^{col}\)；也可把二维网格展平后使用一维位置，但一维相邻不总是二维邻近，例如一行末尾与下一行开头。二维相对 bias 可根据 \((\Delta r,\Delta c)\) 分桶，更直接表达空间关系。

二维 RoPE 常把 head 维度分给横、纵轴，分别按列和行角度旋转；也有更复杂的联合旋转。关键是保持坐标系与 patch 排列一致，并决定分辨率变化时坐标是离散索引还是归一化连续坐标。

## 多模态序列

文本、图像、音频拼成一个序列时，至少有三类信息：模态/segment id、模态内部坐标、全局交互顺序。图像 token 需要二维坐标，音频帧需要时间，文本需要一维 token 位置。可为每个模态使用独立位置机制，再投影到公共空间；也可定义统一连续时间/布局坐标。模态边界 token 不能替代内部位置。

例如图像 24×24 patch 接文本 prompt：若仅按展平后 0…575 编号并让文本从 576 开始，改变图像分辨率会整体平移文本位置，模型可能分布外。可让各模态内部 position 重置，同时用 segment embedding 区分；但 cross-modal attention 是否需要全局距离必须由训练架构定义。

## 插值与工程

可学习二维位置表面对新分辨率常用双线性/双三次插值，但插值坐标、CLS token 分离和长宽比都要正确；插值只是初始化/适配，不保证任意分辨率。Padding 图像、动态 patch、视频帧还需三维 \((t,r,c)\) mask 与位置同步。

## 面试要点

先指出一维展平会扭曲空间邻接，再给出轴向相加、二维相对 bias、轴向 RoPE 三类方案；多模态部分则区分模态身份、内部位置和全局关系。评估应覆盖分辨率、宽高比、帧数和跨模态定位，而非只看固定尺寸分类准确率。
