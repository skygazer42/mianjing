# 25. 超长位置和低精度计算会带来哪些数值稳定问题？

## 位置整数的精度

RoPE 角度是 \(p\omega_i\)。BF16 只有有限尾数，位置 \(p\) 足够大时相邻整数转换后可能相同，导致 \(p\) 与 \(p+1\) 生成相同或错误角度。FP16 还受更小指数范围影响。因此 position_ids 应保持整数，角度乘法与 sin/cos 通常至少在 FP32 计算，再把结果转成 Q/K dtype。

## 三角函数 range reduction

大角度求 sin/cos 需要把值约化到周期内，低精度会放大相位误差；高频通道尤其敏感。提前缓存 cos/sin 时要确认最大长度、base/scale 与 dtype，扩长后不能复用旧表。不同设备数学库的微小误差通常可接受，但若实现先低精度乘再升 FP32，精度已经不可恢复。

## attention 数值

位置缩放会改变 QK 相位和 logit 分布；某些方案还带 attention scaling。若分数方差过大，softmax 饱和，FP16 exp 可能下溢/溢出。实现应使用减最大值的稳定 softmax，mask 采用 dtype 可表示的足够负值。ALiBi 在极长距离的负偏置与 causal mask 相加，也需避免产生不当 Inf 后参与无效运算。

## 诊断方法

比较 FP64/FP32 参考与部署 dtype 在不同位置的 cos/sin 最大误差，检查相邻位置是否仍可区分；验证旋转前后范数保持；统计 QK logits、softmax 熵和非有限值随长度的变化。再比较完整前向与分块/增量前向，定位是位置表还是 attention kernel 问题。

## 常见误区

模型输出在短序列正常不能证明超长数值安全；位置 id 本身是 int64 也不代表后续角度计算没被强制转低精度。相反，所有三角值永久保留 FP32 会增加带宽，通常可 FP32 生成后按运算需要转换，关键是高精度完成角度构造。

面试回答应抓住“大整数分辨率、三角 range reduction、softmax logit”三层，并给出可测的相位/范数/熵诊断。
