# 01. 为什么没有位置编码的 self-attention 无法区分顺序？

## 结论

不含位置信息的 self-attention 对输入排列是置换等变的：把 token 顺序按同一个置换重排，输出只会以相同方式重排，模型看不到“第几个”以及相对先后。若最后再做对称 pooling，它甚至变成置换不变，类似处理一个集合。因此“我爱你”和“你爱我”仅靠相同 token 集合无法稳定区分。

## 数学说明

令输入矩阵为 \(X\)，置换矩阵为 \(P\)。不含位置的单头注意力为

\[
\operatorname{Attn}(X)=
\operatorname{softmax}\left(
\frac{XW_Q(XW_K)^\top}{\sqrt{d_k}}
\right)XW_V.
\]

对重排输入 \(PX\)，有 \(Q'=PQ,K'=PK,V'=PV\)，分数变成 \(P(QK^\top)P^\top\)。行 softmax 与置换相容，最终

\[
\operatorname{Attn}(PX)=P\operatorname{Attn}(X).
\]

逐位置前馈网络、LayerNorm 和残差也保持这一性质，多层堆叠不会凭空产生顺序。Causal mask 虽然按索引限制“只能看过去”，自身已经是一种位置结构；所以说“无位置编码”时必须说明是否仍有非对称 mask。纯双向全连接 attention 在没有任何位置相关信号时最清楚地满足上述结论。

## 如何注入顺序

绝对位置向量可与 token embedding 相加；相对位置方法在注意力分数或 value 中加入距离信息；RoPE 让 Q/K 随位置旋转；ALiBi 按距离加线性偏置。它们共同打破或调整置换对称性，使模型区分方向与距离。

## 常见误区

Token 本身的统计可能泄露某些顺序，例如标点常在句尾，但那不是可靠的位置机制。把序列“按当前数组顺序计算”也不代表模型知道索引，矩阵乘法在维度上并行且共享参数。相反，因果 mask 已使不同位置拥有不同可见集合，decoder 即使不加显式位置向量也并非完全无序，但通常仍缺乏精细距离表达。

面试回答应给出置换等变公式，并主动区分双向 attention 与 causal mask 的情况，这比只说“attention 并行所以不知道顺序”更准确。
