# 07. L1 与 L2 正则如何选择？

## 结论先行

L1 惩罚 \(\lambda\lVert w\rVert_1\)，常产生稀疏解；L2 惩罚 \(\lambda\lVert w\rVert_2^2\)，倾向平滑缩小全部权重。选择取决于特征冗余、稀疏需求、稳定性与部署成本，不能简单说 L1 一定完成正确特征选择。

## 推导与业务例子

L1 在零点不可导，几何约束的尖角更容易与损失等高线相切于坐标轴；L2 梯度连续，会按权重大小持续收缩。广告模型有百万稀疏词项时，L1 可降低活跃特征数；高度相关的多个指标下，L1 可能随机留下一个，L2 往往共同缩小而更稳定。

Elastic Net 同时使用 L1 与 L2，兼顾稀疏和相关特征稳定性。神经网络中的 weight decay 应区分耦合 L2 与 AdamW 的解耦衰减，也常排除 bias 和 norm 参数。

## 工程取舍

正则系数必须在训练折内选择，并同时报告质量、稀疏度、稳定性和推理收益。特征被压成零不等于存在因果关系，更不能作为唯一业务解释。

## 常见坑

- 未标准化特征就比较系数或施加同一正则。
- 把 L2 与任意优化器中的 weight decay 视为完全等价。
- 在全量数据上选择正则强度后再报告验证分数。
