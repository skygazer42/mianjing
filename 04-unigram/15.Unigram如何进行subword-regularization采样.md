# 15. Unigram 如何进行 subword regularization 采样？

## 结论

Unigram 可把同一字符串的多条切分视为概率分布，在训练下游模型时随机采样路径，使模型不依赖唯一边界。常见 alpha 控制分布尖锐程度：alpha 越大越接近最佳路径，越小越平坦；推理时通常回到确定性 Viterbi。

## 概率形式

若路径原分数为 \(P(z)\)，温度化采样可写成

\[
q_\alpha(z\mid x)
=\frac{P(z)^\alpha}{\sum_{z'\in S(x)}P(z')^\alpha}.
\]

\(\alpha=1\) 使用模型原分布；很大时集中于最优路径；接近 0 时合法路径趋于均匀，但实际实现还可能通过 nbest_size 限制候选集合。可在 lattice 上做前向过滤/后向采样，而不枚举所有路径。

## 具体例子

“tokenization” 最佳切分为 [token,ization]，其他高概率路径有 [to,ken,ization]、[token,iza,tion]。训练的不同 epoch 可看到不同组合，迫使 embedding 和 Transformer 学会组合一致语义，对拼写变化、低频形态和数据稀缺可能更稳。

## 工程取舍与误区

随机切分会增加平均 token 数和 batch 方差，训练 token 预算应按实际编码后长度控制。alpha 过小会产生极碎、低概率路径，成为噪声；要联合验证吞吐和下游质量。多 worker 随机种子需可控又不能完全相同。它不是随机删除输入 token，也不是修改词表概率本身；推理开启会破坏缓存与结果可复现。

## 面试回答要点

- 从路径后验/温度化分布采样，不是独立随机切每个字符。
- alpha 控制尖锐度，nbest_size 可限制范围。
- 训练开、推理通常关，作用类似子词级数据增强。
- 代价是长度增长、随机性管理和吞吐波动。

## 延伸追问与复习

采样实现应利用后向路径质量：在位置 i，对每条出边按其温度化权重与从终点可完成路径的总质量计算条件概率，再随机选边，保证得到的是完整路径分布而非局部随便选择。实验需固定总训练 token 或算力，并报告采样后长度分布；否则更碎的配置实际看到了更多 token。线上通常设 alpha 对应确定性 Viterbi，并把训练 RNG 与数据 shuffle RNG 分开保存。
