# 03. 什么是 Unigram 分词 lattice？

## 结论

Lattice 是把所有合法子词切分紧凑表示成一个有向无环图：节点是字符串位置，若子串 \(x[i:j]\) 在词表中，就从 i 到 j 建一条 token 边，边权为 \(-\log p(t)\)。任意从 0 到文本末尾的路径对应一种完整切分。

## 构建方法

对规范化后的片段，在每个起点 i 查询所有可匹配 vocab token，可用 Trie 避免枚举全部终点。为每个匹配创建 (i,j,token,cost)；基础字符或 byte fallback 保证至少存在一条完整路径。图天然按位置向右，因此无环，适合 Viterbi、forward-backward、n-best 和采样。

## 具体例子

字符串 “abc”，词表含 a、b、c、ab、bc、abc。图中有 0→1(a)、0→2(ab)、0→3(abc)，1→2(b)、1→3(bc)，2→3(c)。路径可为 [abc]、[a,bc]、[ab,c] 或 [a,b,c]。最长 token 只是其中一条边，最优路径由所有边的总代价决定。

## 工程取舍与误区

若词表和最大 token 长度很大，边数会增加；Trie、最大长度、候选剪枝可控制构图。Unicode normalization 后的位置与原文 offset 需另维护 alignment。不要显式枚举所有路径，其数量可能指数级；DP 只保存每个位置的最优值或前向/后向总量。特殊 token 与空格元符号通常在构图前后有独立规则。

## 面试回答要点

- 节点是位置，边是词表 token，路径是完整切分。
- 边权通常是负对数概率，图因位置递增而是 DAG。
- Viterbi 找一条最优路，forward-backward 汇总所有路径。
- Trie 用于高效找到从每个起点出发的边。

## 延伸追问与复习

可以手画四个位置的 DAG，并分别执行三种操作：Viterbi 在每个节点留最小代价回指；forward 用 log-sum-exp 汇总所有入边；采样则结合边权与剩余路径质量随机选边。三者共享同一 lattice，却回答不同问题。生产实现应断言终点可达、所有边都严格向右、token 表面与原文片段一致，并限制最大 piece 长度和单输入长度。若 normalization 改变字符数，还需让节点位置对应规范化文本，并另行维护到原文的 alignment。
