# 05. 前向算法如何计算所有切分的总概率？

## 结论

前向算法不是挑一条路径，而是把到达每个字符串位置的所有切分概率相加。句子的边缘概率等于终点前向值；在 log 域用 log-sum-exp 计算，可避免路径概率连乘下溢。这一“对隐变量切分求和”是 Unigram 训练与 Viterbi 解码的核心区别。

## 公式

令 \(\alpha[j]\) 表示覆盖前 j 个单位的总概率：

\[
\alpha[0]=1,\qquad
\alpha[j]=\sum_{(i,j,t)}\alpha[i]p(t).
\]

在 log 域令 \(A[j]=\log\alpha[j]\)，则

\[
A[j]=\operatorname{LSE}_{(i,j,t)}
\big(A[i]+\log p(t)\big).
\]

终点 \(A[n]\) 是 \(\log P(x)\)。

## 具体例子

“ab” 有路径 [ab] 和 [a,b]，其总概率是 \(p(ab)+p(a)p(b)\)，而不是二者最大值。若 p(ab)=0.05、p(a)=0.2、p(b)=0.3，则 \(P(x)=0.11\)；Viterbi 只会选择 0.06 的 [a,b]。训练需要总概率，因为真实语料只给字符串，没有告诉 tokenizer 哪条切分是正确标签。

## 工程取舍与误区

直接在普通浮点域相乘相加，长句很快下溢到 0；应实现稳定 LSE：取最大值 m，再算 \(m+\log\sum e^{v_i-m}\)。若用剪枝丢掉低概率边，得到的是近似似然，要评估误差。前向值还需与后向值结合计算每条边的 posterior，进而得到 EM 的期望 token 计数。

## 面试回答要点

- Viterbi 求 max，forward 对所有路径求 sum。
- 边缘概率用于无监督隐切分训练。
- log-sum-exp 是数值稳定关键。
- forward-backward 可得到 token 边的后验期望次数。

## 延伸追问与复习

后向量 \(\beta[i]\) 从终点反向汇总所有到末尾的路径，某条边 \(i\to j\) 的 posterior 由前向、该 token 概率、后向和句子归一化常数共同得到。把所有同 token 边 posterior 相加，就是 EM 的期望计数。实现测试可对短字符串穷举所有路径，把直接求和结果与 forward 的 logZ 比较；再检查每个句子中各完整路径 posterior 总和为 1。若代码用 max 代替 log-sum-exp，它实际上训练的是 hard/Viterbi assignment，会系统性忽略分词不确定性。

在含重复句子的语料中，可以只计算一次前向后向再乘句频，但句频权重必须同时作用于似然和期望计数。训练日志若出现不可达句子，应立即检查 required chars 或 fallback，而不是把其概率当零后继续，因为负对数会成为无穷并污染统计。
