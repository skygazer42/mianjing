# 19. Whole Word Masking 与 WordPiece 是什么关系？

## 结论

Whole Word Masking（WWM）是预训练时的 mask 选择策略，不是新的 tokenizer。文本仍先被 WordPiece 切成子词；若某个原始词被选中，属于该词的全部 wordpieces 一起参与 mask 决策，从而减少模型只凭未遮住的同词片段猜出目标的捷径。

## 核心原理

普通 MLM 可以单独遮 [play] 而保留 [##ing]，模型容易利用同词剩余部分。WWM 先根据 BasicTokenizer 的词边界或 word_ids 把 [play, ##ing] 归为一组，再以组为单位选择，通常仍按既定比例对组内 token 执行 [MASK]/随机 token/保持原 token 的替换策略。损失仍在被选 token 位置计算。

## 具体例子

“unbelievable” 切成 [un, ##believ, ##able]。普通 mask 可能只遮 ##believ；WWM 选中该词时三项都作为预测目标。中文若 BasicTokenizer 将每个汉字视为独立词边界，简单依赖 ## 分组的 WWM 可能退化为逐字 masking；中文 WWM 常需要外部分词或专门 word boundary 信息。

## 工程取舍与误区

WWM 增加预测难度，不保证所有任务都优于 token masking；mask 比例按词组采样后，实际 token 比例可能波动，需要校准。不能仅通过“连续没有 ##”推断任意 tokenizer 的词边界，应使用可靠 word_ids。动态 masking 的随机种子、特殊 token 排除和 padding mask 也要正确处理。

## 面试回答要点

- WordPiece 负责切分，WWM 负责选择哪些位置遮蔽。
- 目标是把同一词的所有子词作为一个 mask 单位。
- 中文 WWM 需要额外说明词边界来源。
- 训练输入仍是原词表 ID，不会因此新增 token。

## 延伸追问

实现 WWM 时可先建立 word_id 到 token positions 的映射，排除 [CLS]、[SEP]、[PAD]，再随机选词组直到接近 token mask 预算；直接随机选词会让长词组使比例偏高。对一个词的所有片段执行替换时，每个位置是否独立采用 80/10/10 规则要遵循具体训练方案，并保持 loss mask 与选择一致。

验证可构造包含单片段词、多片段词和特殊 token 的句子，固定随机种子后检查被选组不会只遮一半。还应统计实际被预测 token 比例和每批方差，确保长复合词没有让 mask 预算系统性偏离设定值。
