# 24. 如何给 BERT 添加领域 WordPiece 词汇？

## 结论

向已有 BERT 添加领域词需保持所有旧 token ID 不变，将新项追加到 vocab，调用模型 resize 扩展 embedding/MLM decoder，初始化新行并继续预训练。只有当领域术语当前切分显著过碎且有足够适配语料时，收益才可能覆盖兼容与训练成本。

## 实施步骤

先在领域语料统计高 fertility、稳定高频且有业务意义的候选，过滤隐私 ID 和偶然字符串。明确新 token 是词首还是 ## 续接，并检查 longest-match 是否会改变包含关系。追加 ID 后扩展输入 embedding、输出 decoder 权重与 bias；若权重 tying，保持共享。新向量可由旧分词子 token embedding 平均初始化，再进行领域继续预训练并混入通用数据。

## 具体例子

“electroencephalography” 原来拆成十多个片段，若在医学语料极高频，可新增完整词或可复用词根。新增 “graph” 可能改变许多普通词的最长匹配，而新增完整医学词影响范围更局部。需要用旧通用 corpus 回归分词变化，并比较领域序列长度、MLM loss 和下游 F1。

## 工程取舍与误区

新 token 不会因字符串有意义就自动获得语义；没有继续训练时只是随机或平均向量。大量整词项容易稀疏、扩大 softmax 并降低形态共享。量化 checkpoint、蒸馏模型和 adapter 可能假设旧 vocab shape，需同步处理。若只需要新知识而不是减少显著 token 成本，继续预训练或微调通常更简单。

## 面试回答要点

- 旧 ID 不动、新 ID 追加、模型矩阵同步 resize。
- 新词选择基于频次、碎片度、复用与业务价值。
- 初始化后仍必须训练。
- 用领域收益、通用回归和部署兼容共同决策。

## 延伸追问

新增项还可能与旧项发生最长匹配竞争，使很多并非目标术语的词改变切分。发布前应对通用 corpus 计算“ID 序列发生变化的样本比例”，对变化最大的模式人工审计。若只需让一个特殊实体保持原子，可用 added token，但其边界和大小写匹配规则也必须明确。
