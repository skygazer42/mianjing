# 25. 哪些指标能评估 WordPiece 的碎片化程度？

## 结论

核心指标是每个 basic word 的子词数 fertility，但必须结合 tokens/character、[UNK] 率、完整词命中率、长度分位数和分语言/领域统计。碎片化低并不自动代表模型更好，因为大量低频整词虽缩短序列，却可能难以学到稳定表示。

## 指标定义

若样本有 \(W\) 个 basic words、产生 \(T\) 个非特殊 wordpieces，则 fertility 可写为 \(T/W\)。还可统计 proportion_split（被拆成两片以上的词占比）、pieces-per-split-word、每字符 token 数和 P50/P95/P99。对中文逐字 basic token，word 口径失去语言学意义，应使用 chars/token 或外部分词后的辅助指标。

## 评测设计

在独立集按语言、脚本、实体类型、词频桶和领域报告。特别关注人名、药名、URL、拼写错误、混合脚本和长复合词。将 token 长度换算成实际模型截断率：在固定 512 上限下，有多少样本丢失尾部。再与编码吞吐、词表项训练频次及下游任务一起分析。

## 工程取舍与误区

只看平均 fertility 会被大量短常见词稀释，P99 才能暴露长尾。把 [UNK] 算作一个 token 会让碎片化看似极低，却实际上丢了整词信息，因此必须并列报告未知率。跨 tokenizer 比较前要统一 BasicTokenizer 的 word 定义，否则分母不同。词表越大往往降低 fertility，但增加 embedding 成本。

## 面试回答要点

- fertility 是主指标，但不能脱离 [UNK] 和分位数。
- 分组和长尾比单一总体平均重要。
- 真实影响是截断、算力和下游质量。
- 公平比较需统一原文、预分词口径和模型预算。

## 延伸追问

还可以按词频桶绘制 fertility：高频词过碎说明词表容量分配异常，低频词适度碎是子词共享的预期。对业务实体单独报告“完全变成 [UNK]”和“平均片段数”，因为二者损害不同。最终把分词长度映射为截断率和每秒样本数，才能连接到真实成本。
