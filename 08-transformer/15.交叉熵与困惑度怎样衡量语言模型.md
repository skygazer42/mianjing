# 15. 交叉熵与困惑度怎样衡量语言模型？

## 结论

语言模型训练通常最小化真实下一个 token 的负对数似然，也就是 token 级交叉熵。困惑度（perplexity, PPL）是平均负对数似然的指数，直观表示模型在每一步面对的“等效候选数”。loss 越低、PPL 越低通常说明对同分布文本预测更好，但它们不是事实性、指令遵循或人类偏好的完整指标。

## 公式

对有效 token 集 \(\mathcal T\)，

\[
\mathcal L=-\frac{1}{|\mathcal T|}\sum_{t\in\mathcal T}\log p_\theta(x_t\mid x_{<t}),\qquad
\operatorname{PPL}=e^{\mathcal L}.
\]

若使用以 2 为底的平均交叉熵，则 PPL 为 (2^{\mathcal L_2})。例如自然对数 loss 为 (ln 10\approx2.303)，PPL 为 10。实现中对 logits 使用 `log_softmax + NLL` 或 fused cross entropy，避免先算概率再取对数导致下溢。

## 正确聚合

不同 batch 含有效 token 数不同，应累加 token 级 NLL 再除以总有效 token，不能先平均每个 batch loss 后等权平均。padding、prompt-only 区域和跨文档边界要按评测定义排除。滑窗评测长文本时，每个 token 应只计一次，并给予尽可能一致的上下文，否则窗口边界会人为抬高 PPL。

## 比较限制

不同 tokenizer 的 PPL 不能直接横比：切分粒度改变了预测步数和词表熵。至少应在同 tokenizer、同文本规范化、同上下文长度下比较，或换算 bit-per-byte/character 作为更可比的补充。低 PPL 也可能来自数据泄漏或记忆测试集；对话模型经过偏好对齐后，通用 PPL 甚至可能略变差但交互质量更好。

## 面试回答要点

写出 NLL 与指数关系，解释 token 加权聚合、ignore mask 和 tokenizer 不可比性。延伸追问可讨论 label smoothing 为什么让训练 loss 与严格似然不再完全一致。
