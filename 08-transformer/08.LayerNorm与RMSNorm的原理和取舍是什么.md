# 08. LayerNorm 与 RMSNorm 的原理和取舍是什么？

## 结论

LayerNorm 对单个 token 的隐藏维做去均值和方差归一化；RMSNorm 不减均值，只按均方根缩放。两者都不依赖 batch 内其他样本，适合变长序列与自回归推理。RMSNorm 运算更少，在许多现代 LLM 中常见，但不能简单断言它在所有架构上都更好。

## 公式

对 (x\in\mathbb{R}^{d})，LayerNorm 为

\[
\mu=\frac1d\sum_i x_i,\quad \sigma^2=\frac1d\sum_i(x_i-\mu)^2,\quad
y_i=\gamma_i\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_i.
\]

RMSNorm 为

\[
\operatorname{rms}(x)=\sqrt{\frac1d\sum_i x_i^2+\epsilon},\qquad
y_i=\gamma_i\frac{x_i}{\operatorname{rms}(x)}.
\]

它保留整体平移信息，通常没有 bias；两者都通过 \(\gamma\) 恢复各通道可学习尺度。

## 为什么不用 BatchNorm

BatchNorm 的统计量依赖 batch 和位置，变长输入、micro-batch、训练与自回归推理之间容易产生统计不一致。Layer/RMSNorm 在每个 token 内部归约隐藏维，训练与推理形式一致，也不需要维护移动均值。不过归约仍会带来同步和内存访问开销，常与其他算子融合。

## 工程陷阱

半精度计算均值或平方和可能溢出/丢精度，常先转 FP32 归约，再转回输入 dtype。`epsilon` 太小可能导致近零向量放大，且把 epsilon 放在平方根内外会产生不同结果。权重加载时还要确认 norm 是否有 bias、epsilon 值、Pre/Post-Norm 位置，否则参数形状能对上但输出仍不一致。

## 取舍与回答要点

LayerNorm 同时具有平移与尺度不变性，RMSNorm 主要提供重缩放不变性；后者更简单、更快，经验上常足够稳定。面试中应明确归一化轴是 hidden dimension，不是 sequence 或 batch；再给出两者公式、数值精度和架构兼容性，避免只说“RMSNorm 是 LayerNorm 的优化版”。
