# 09. Pre-Norm 与 Post-Norm 有什么区别？

## 结论

区别在归一化相对子层和残差加法的位置。Post-Norm 原始形式是 \(y=\operatorname{Norm}(x+F(x))\)；Pre-Norm 是 \(y=x+F(\operatorname{Norm}(x))\)。现代深层 LLM 多采用 Pre-Norm，因为残差主干保持未经归一化阻断的恒等路径，深层训练通常更稳；Post-Norm 可能获得更强的逐层变换，但对初始化、学习率和 warmup 更敏感。

## 梯度与表示

Pre-Norm 中每一层都有 `x -> x + ...` 的直接路径，跨多层传播时至少保留恒等项，梯度较容易到达浅层。Post-Norm 的梯度每层都必须经过 Norm 的 Jacobian，层数增大时更容易不稳定。相反，Pre-Norm 的残差状态会不断累加，各层只看到归一化后的输入，深层可能呈现“有效深度不足”或表示变化偏小，因此不能说它理论上全面优于 Post-Norm。

## 完整结构

典型 Pre-Norm decoder block：

```text
h = x + Attention(Norm1(x))
y = h + FFN(Norm2(h))
```

模型堆栈末尾一般还要 final norm，之后才接 LM head。Post-Norm 则在每次残差相加之后做 norm，最终是否再 norm 取决于具体架构。读取 checkpoint 时必须以配置和实现为准，不能凭模型年代猜测。

## 工程取舍

超深网络还常结合残差缩放、输出投影小初始化、DeepNorm 或 sandwich norm。把一个已训练的 Post-Norm 模型直接改成 Pre-Norm 并复用权重，函数会发生根本变化，通常需要重新训练或专门转换。混合精度下 norm 的统计计算也应使用更高精度。

## 面试回答要点

先写两条公式，再从梯度恒等路径解释训练稳定性，最后说出 Pre-Norm 需 final norm 与潜在有效深度问题。常见误区是把“pre”理解为 block 之前只做一次 norm；实际上 attention 和 FFN 两个子层通常各有自己的 norm。
