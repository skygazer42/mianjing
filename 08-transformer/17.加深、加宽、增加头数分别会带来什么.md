# 17. 加深、加宽、增加头数分别会带来什么？

## 结论

加深、加宽和增加头数都能改变容量，但作用与代价不同。加深增加连续计算步骤和表示组合层级；加宽提高每个 token 的通道容量并以近似平方速度增加矩阵参数；增加头数在总宽度固定时主要重新划分注意力子空间，并不会自动增加总参数。选择必须同时考虑质量、训练稳定性、并行效率与推理延迟。

## 参数与计算

密集 Transformer 主参数近似与 (Ld^2) 成正比。层数 (L) 翻倍，参数和串行层延迟约翻倍；宽度 (d) 翻倍，在 FFN 比例不变时参数/FLOPs 约变四倍，但更大的 GEMM 往往有更高硬件利用率。头数 (h) 增加且 (d) 固定时 (d_h=d/h) 变小，QKV/O 总矩阵形状大体不变，attention 分数元素总数也仍是 (B h S^2)，每元素 value 维变小，总 FLOPs 同阶。

## 表达与优化差异

深度让信息经历更多次 token 混合和非线性变换，可能提升组合推理，但梯度、激活内存与流水线气泡更难处理。宽度容纳更多并行特征，训练较稳，却显著扩大参数、优化器和 KV 表示。更多头提供更多独立注意力分布，但 head dimension 过小可能损害内容匹配或位置编码频率表达；头数过多还造成小算子与调度开销。

## 工程选择

张量并行倾向切大矩阵，宽模型更易摊平通信；流水线并行需要足够层数切 stage；decode 对逐层启动和内存带宽敏感，过深会增加每 token 串行延迟。GQA 可让 Q 头数多而 K/V 头数少，分离表达多样性与缓存成本。

## 常见误区与回答要点

不能说“头越多越好”或“同参数下深一定优于宽”；最优比例会随数据、上下文和硬件变化。面试回答应先固定参数预算，再比较三者对串行深度、矩阵尺寸、head dimension 和部署的影响，并指出实际通常遵循经验 scaling 配方做联合搜索。
