# 02. 一个 Transformer block 的完整数据流是什么？

## 结论

以现代 decoder-only 的 Pre-Norm block 为例，输入 (X\in\mathbb{R}^{B\times S\times d}) 先归一化，再经过带因果遮罩的多头自注意力并与输入残差相加；随后再次归一化，经过 FFN/MLP，再做第二次残差相加。可写为：

\[
H=X+\operatorname{Attn}(\operatorname{Norm}(X)),\qquad
Y=H+\operatorname{FFN}(\operatorname{Norm}(H)).
\]

## 核心数据流

注意力分支先线性投影得到 (Q=XW_Q,K=XW_K,V=XW_V)，拆成多个 head；给 Q、K 注入位置信息后，计算

\[
A=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_h}}+M\right),\quad O=AV,
\]

其中 (M) 包含 causal/padding mask。各头输出拼接后乘 (W_O)。FFN 分支通常先升维到约 (4d)（SwiGLU 常用不同倍率），激活/门控后再降回 (d)，所以两条残差分支的输入输出形状必须一致。

在完整模型中，token id 先经 embedding 得到 (X)，堆叠 (L) 个 block 后通常还有 final norm，再通过 LM head 映射到词表 logits。训练时对 logits 与下一个 token 标签求交叉熵；推理时根据最后位置的 logits 采样。

## 具体例子

若 `B=2,S=128,d=768,h=12`，每头维度 `64`，Q 的逻辑形状由 `[2,128,768]` 变为 `[2,12,128,64]`，注意力分数为 `[2,12,128,128]`，合并后回到 `[2,128,768]`，才能与残差相加。形状错误、transpose 后非连续、mask 广播错轴是手写实现最常见的问题。

## 工程取舍与误区

不同模型可能使用 Post-Norm、并行 attention/FFN 分支、RMSNorm、MQA/GQA 或 MoE，但“跨 token 混合 + 逐 token 通道变换 + 残差稳定路径”这一骨架不变。面试时不要把 embedding、位置编码或 LM head 误说成每个 block 都重复一次。

## 面试回答要点

先给两行残差公式，再沿形状讲 QKV、mask、合头、FFN，最后补充模型首尾结构，能证明你理解的是数据流而不只是模块名。
