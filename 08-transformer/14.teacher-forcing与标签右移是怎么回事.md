# 14. teacher forcing 与标签右移是怎么回事？

## 结论

teacher forcing 指训练自回归模型时，第 (t) 步的条件输入使用真实历史 token，而不是模型自己前一步采样的结果。标签右移/错位对齐则保证位置 (t) 的隐藏状态预测下一个 token (x_{t+1})。两者常同时出现，但概念不同：前者是训练条件策略，后者是输入与监督目标的索引关系。

## 对齐例子

原序列为 `<bos> 我 爱 NLP <eos>`。模型输入可以是 `<bos> 我 爱 NLP`，对应标签是 `我 爱 NLP <eos>`。很多 causal LM API 直接接收同一串 `input_ids` 作为 `labels`，在模型内部做 `logits[:, :-1]` 与 `labels[:, 1:]` 的 shift；如果数据管线已手动 shift，而模型又 shift 一次，就会错两位，loss 可能仍能计算但学习目标已错。

因果 mask 是不可缺的另一环。即使标签已右移，若位置 (t) 在自注意力中能看到 (x_{t+1})，模型仍可泄漏答案并得到虚假的低 loss。正确训练同时需要输入/标签对齐、因果遮罩与 padding/ignore mask。

## 训练—推理差异

训练时真实历史始终正确，可以并行计算所有时间步；推理时模型只能把自身已生成 token 追加回输入，错误会进入后续条件，这称为 exposure bias。scheduled sampling 曾尝试混入模型预测，但对大规模语言模型并非默认方案；更常见的是通过高质量预训练、序列级偏好优化、解码策略和数据覆盖改善鲁棒性。

## 工程细节

指令微调可把 prompt 区域标签设为 `-100`，只监督答案，但 prompt token 仍作为上下文参与注意力。packing 多条样本时应防跨样本注意并分别设置 loss mask。EOS 是否监督会影响模型学会何时停止，不能一律丢弃。

## 面试回答要点

用五个 token 写出 input/label 错位表，说明 teacher forcing 使训练可并行，再指出 exposure bias。最常见错误是把“右移”说成给所有 token 的 position id 加一，二者毫无关系。
