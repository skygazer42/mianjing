# 15. router noise 和 jitter 有什么作用？

## 结论

Router noise/jitter 在训练时对输入、logits 或 gate 加小随机扰动，打破专家分数平局、鼓励探索，防止早期微小优势迅速固化为 collapse。它类似路由层正则化，不保证负载均匀，也不应在普通确定性推理中随意开启。

## 常见形式

可对 router 输入做乘性 jitter：

\[
\tilde x=x\odot u,\qquad
u\sim Uniform(1-\epsilon,1+\epsilon),
\]

再计算 \(W_r\tilde x\)；也可对 logits 加 Gaussian/Gumbel noise 后 top-k。不同噪声对应不同采样性质，幅度与是否参与 gate combine 必须按实现定义。Gumbel 类可近似从分类分布采样，均匀 jitter 更像输入扰动。

## 为什么有帮助

假设两个未训练 experts 分数仅差 \(10^{-4}\)。完全确定 top-1 会让同一类 token 总进第一个，第二个得不到任务梯度；适量噪声让二者都被尝试，模型可以从实际损失中学出更可靠差异。它还能防止 router 过度依赖某个脆弱隐藏维度。

## 代价与调度

噪声过大会让路由近似随机，增加同一 token 输出方差、破坏专业化并加剧容量波动。常见做法训练早期较强、随后衰减；推理关闭并使用确定 top-k。若训练从未在无噪声路由下适配，关闭时仍可能分布变，因此需验证。分布式可复现还要管理 RNG，gradient checkpoint重算必须复现同一噪声。

Noise 与 load balancing loss、z-loss职责不同：前者探索，balance控制使用，z-loss控尺度。三者超参相互影响，不能一个指标异常就全加大。

## 面试要点

回答应说明扰动加在哪里、如何打破早期正反馈、为何推理关闭，以及幅度过大导致随机路由和容量抖动。
