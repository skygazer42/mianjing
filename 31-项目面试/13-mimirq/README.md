# MimirQ：项目面试题

仓库：[`skygazer42/MimirQ`](https://github.com/skygazer42/MimirQ)。MimirQ 是中文优先、全栈开源的企业 RAG 知识库，关注解析、治理、业务切块、混合检索、重排、逐句引用和 Golden 回归。当前仓库展示 FastAPI 后端、独立 worker、PostgreSQL/Redis/Milvus 等基础设施、30 个解析后端、86 种切块策略、13 类重排器及 Dify 外部知识库/HTTP 集成。
