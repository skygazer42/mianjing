# Digital Human：项目面试题

仓库：`skygazer42/digital-human`（私有，分支 `meta-livehuman`）。这是离线优先的多模态数字人开发栈，整合 Electron/Vue、Python gRPC/WS 控制平面、FunASR、F5-TTS、llama.cpp、LiveTalking、SRS/WebRTC、知识问答、人脸/声纹/动作检测，并提供按键、实时、大屏和 Web Agent 等页面。
