# 02. Scaled dot-product attention 的完整公式和张量形状是什么？

## 公式

单头 attention 为

\[
S=\frac{QK^\top}{\sqrt{d_k}}+M,\qquad
A=\operatorname{softmax}(S,\text{dim}=-1),\qquad
O=AV.
\]

\(M\) 是可选加性 mask/bias。Softmax 沿 key 维做，使每个 query 对可见 keys 的权重和为 1。多头结果拼接后再过输出投影 \(W_O\)。

## 常见张量形状

输入 \(X\) 为 \([B,L_q,d_{\text{model}}]\)。投影并拆头后：

\[
Q:[B,H_q,L_q,d_h],\quad
K:[B,H_{kv},L_k,d_h],\quad
V:[B,H_{kv},L_k,d_v].
\]

标准 MHA 有 \(H_q=H_{kv}=H\) 且常取 \(d_h=d_v=d_{\text{model}}/H\)。Score 为 \([B,H,L_q,L_k]\)，输出每头 \([B,H,L_q,d_v]\)，转置并拼接为 \([B,L_q,Hd_v]\)，最后映射到 \(d_{\text{model}}\)。GQA/MQA 中 K/V 头会按组广播给 query heads，但不一定真的复制内存。

## 小例子

\(B=2,L=4,d_{\text{model}}=8,H=2,d_h=4\)。Q、K、V 都为 \([2,2,4,4]\)，QK 转置乘得到 \([2,2,4,4]\)，AV 回到 \([2,2,4,4]\)，拼头为 \([2,4,8]\)。若 cross-attention 的 query 长 3、source 长 5，则 score 是 \([2,2,3,5]\)，并非方阵。

## 易错点

矩阵转置只交换最后的序列与 head_dim 相关轴，不能误交换 batch/head。Mask 要可广播到 \([B,H,L_q,L_k]\)，且被屏蔽的是 key 位置；query padding 输出还需在后续清理或损失中忽略。Softmax dim 写成 query 轴会得到完全不同语义。

实现还应使用稳定 softmax，并避免为了 GQA 显式 repeat K/V。面试时从输入到 QKV、score、概率、输出逐步报 shape，通常能同时证明公式、mask 和多头布局理解正确。
