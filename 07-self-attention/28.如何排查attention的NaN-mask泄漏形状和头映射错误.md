# 28. 如何排查 attention 的 NaN、mask 泄漏、形状和头映射错误？

## 分层检查

固定一个极小可手算 batch，依次记录 Q/K/V shape 与有限值、旋转后范数、score 范围、mask、softmax 行和、输出。先与简单 FP32 reference 对比，再切换融合 kernel、低精度和 GQA；一次只改变一个变量。

## NaN

定位第一个非有限张量。QK 先 Inf 说明激活/累积或 scale 问题；softmax 才 NaN 常是漏减 max、全 mask 行或 \(-\infty-(-\infty)\)；输出才 NaN 可检查 V、dropout和下游。监控每层每头 RMS、max 与 softmax 熵，而非只在模型末端断言。

## Mask 泄漏

做扰动测试：把未来、PAD 或其他 packed segment token 改成极大随机值，目标位置输出应不变。直接断言 masked probabilities 和 gradients 为 0。检查 bool True 语义、三角方向、广播轴和 \(L_q\ne L_k\) 对齐。

## Shape 与 GQA

在每个 KV head 填独特常数，验证对应 Q group 输出，能抓到 repeat 轴和 head mapping 错误。Transpose 后检查 stride/contiguous，避免把 \([B,L,H,D]\) 错 view 成 \([B,H,L,D]\)。对 MHA/GQA/MQA 分别与显式广播参考比较。

## 回归集合

覆盖长度 1、非整齐长度、左右 padding、全有效/部分有效、cross-attention、causal、dropout、混合精度和反向 gradcheck。Full forward 与逐 token 对应 logits应接近。记录实际 kernel，自动回退可能解释性能而非数值差异。

面试回答最好按“QKV → score → mask → softmax → AV”定位，并为每类错误给一个差分不变量。这样比盲目换 dtype 或关闭 Flash 更可复现。
