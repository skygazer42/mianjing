# 17. Attention dropout 应加在哪里，训练和推理有何不同？

## 标准位置

常见做法是在 softmax 得到注意力概率后、与 V 相乘前做 dropout：

\[
\tilde A=\frac{Z\odot A}{1-p},\qquad O=\tilde AV,
\]

其中 \(Z\sim\operatorname{Bernoulli}(1-p)\)。倒置缩放使训练期 \(\mathbb E[\tilde A]=A\)，推理关闭 dropout，不再随机也不再缩放。它随机切断部分 query-key 路由，防止过度依赖单一位置。

## 与其他 dropout 区分

Residual dropout 常加在 attention 输出投影后；embedding dropout 作用输入；dropout Q/K/V 或 logits 是不同变体，不能都叫 attention dropout。概率 dropout 后单次每行之和不一定为 1，这是预期现象，不应再次归一化，否则改变期望和训练定义。

## Mask 与数值

先 mask、再 softmax、再 dropout。若先 dropout logits 或在 mask 前处理，语义不同。被 causal/padding 屏蔽的位置概率本来为 0，dropout 不会恢复它。短序列或有效 key 很少时，较大 p 可能把唯一有效边随机丢掉，导致该 query 输出为零；某些任务需降低 dropout。

## 训练推理一致性

评估/生成必须切换 eval mode；忘记关闭会导致相同输入输出漂移。分布式与 gradient checkpointing/FlashAttention 反向需保存或可重建一致 RNG 状态，否则重算得到不同 mask，梯度错误。确定性测试应固定种子并理解不同 kernel 的随机数消费顺序可能不同。

现代大规模预训练有时将 attention dropout 设为 0，以最大吞吐和训练稳定，再依赖数据规模、权重衰减等正则；小数据微调可能受益。选择应看过拟合、质量和 kernel 性能，而非默认值。

面试回答应明确“softmax 后、AV 前、训练随机缩放、推理关闭”，再区分 residual dropout 和概率和不再为 1 的现象。
