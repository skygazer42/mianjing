# 27. 量化 Q/K/V 和 attention 中间值有哪些风险？

## 敏感路径

QK 点积经过 softmax，logit 的小误差在分数接近或温度尖锐时可能放大为排序/概率变化；V 误差则被权重线性混合。Q/K 的异常值、不同 head/position 的尺度差异使单一 per-tensor scale 容易浪费动态范围。相较线性权重，attention 激活随输入变化，校准更难。

## 量化粒度

可对 Q/K/V 使用 per-token、per-head、per-channel 或分组 scale。细粒度更准确但 scale 存储和 kernel 复杂。K/V 若跨很多位置，固定 scale 需要覆盖分布漂移；对称 INT8 较简单，INT4/FP8 更依赖硬件、校准与累积精度。点积通常用更高精度累积，softmax 的 max/sum 建议 FP32。

RoPE 应在量化前还是后取决于实现；旋转会混合维度并改变每通道范围。训练/校准与部署顺序必须一致。Mask 的 \(-\infty\) 不应被普通整数 scale量化后失效，通常在反量化 score 或高精度域加入。

## 误差评估

先比较各层 Q/K/V 范围、饱和比例和重建误差，再看 score 误差、top attention 边重合、输出余弦和最终 perplexity/任务质量。长上下文、稀有大激活、不同语言及 batch 都要覆盖。只测短随机输入会低估累积和极值问题。

候选方案可保留 Q/K 或 softmax 高精度，只量化 V/权重；或使用量化候选计算后在关键层高精度。最终收益取决于是否有原生低比特 attention kernel；若频繁反量化，内存虽省但延迟未必下降。

面试回答应指出“Q/K 误差经 softmax 非线性放大，V 误差线性传播”，再讲粒度、累积精度、RoPE 顺序和端到端校准，不能只给位宽压缩比例。
