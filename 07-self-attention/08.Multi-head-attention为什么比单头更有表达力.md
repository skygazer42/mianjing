# 08. Multi-head attention 为什么比单头更有表达力？

## 核心直觉

多头将隐藏表示投影到多个独立 Q/K/V 子空间，每个头拥有自己的 attention 分布：

\[
head_h=\operatorname{Attn}(XW_Q^h,XW_K^h,XW_V^h),
\quad
O=\operatorname{Concat}(head_1,\ldots,head_H)W_O.
\]

不同头可同时建立不同关系，例如一个偏局部相邻，一个追踪指代，一个读取分隔符。单头对每个 query 只有一套权重，用同一分布混合所有 value，较难同时保留彼此冲突的路由。

## 为什么计算量没有按头数简单翻倍

通常保持总投影宽度 \(Hd_h=d_{\text{model}}\)。一个 \(d_{\text{model}}\) 宽的单头与 \(H\) 个 \(d_h=d_{\text{model}}/H\) 的头，QKV/输出投影总参数和主要 FLOPs 同阶。多头的区别是把 score 分成 \(H\) 个 \(L\times L\) 矩阵，提供多套归一化，而不是把总维度扩大 \(H\) 倍。

## 表达边界

“每个头学习一种语言学关系”只是可能的解释，不是保证。头之间可冗余，部分头剪枝后质量变化小；输出投影会混合头，单独观察热力图不等于功能证明。头太多导致 \(d_h\) 太小，单头内容容量不足；头太少则路由多样性受限。

MQA/GQA 让多个 Q heads 共享 K/V，仍保留多套 query 和 attention 分布，因此质量通常介于完整 MHA 与极致共享之间，主要节省 K/V 投影及解码带宽。多头数也与位置频率、tensor parallel 切分和 kernel 对齐相关。

## 如何验证

做 head ablation、注意力熵/相似度统计和任务指标，而非只看图。选 head 数时固定模型宽度与参数预算，比较质量、吞吐与并行通信。

面试回答应强调“多套子空间 + 多套 softmax 路由”，解释总宽度固定时复杂度为何同阶，并主动指出头冗余和 \(d_h\) 过小的折中。
