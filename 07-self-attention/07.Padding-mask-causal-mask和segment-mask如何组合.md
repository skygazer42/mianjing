# 07. Padding mask、causal mask 和 segment mask 如何组合？

## 三种约束

Padding mask 屏蔽无效 PAD key；causal mask 屏蔽未来 key；segment/block mask 阻止 packed 独立样本之间互相注意。最终可见条件通常是

\[
visible(i,j)=valid_q(i)\land valid_k(j)
\land(j\le i)\land(segment_i=segment_j),
\]

再将不可见位置的 logit 设为 \(-\infty\)。具体是否需要 valid_q 取决于后续是否直接丢弃 PAD query 输出，但 key 屏蔽不可少。

## 广播形状

Key padding mask 常由 \([B,L_k]\) 扩成 \([B,1,1,L_k]\)；causal mask 为 \([1,1,L_q,L_k]\)；segment mask 为 \([B,1,L_q,L_k]\)。逻辑 AND 可见 mask 或 OR 屏蔽 mask 后广播到所有 heads。GQA 不改变 mask 的 query head 语义。

Packed 两段 A、B 时，即使都在同一 causal 序列里，B 的位置会满足 \(j\le i\) 而看到 A；必须由 segment mask 再切断。位置 id 重置也不会屏蔽信息，label 边界同样要独立处理。

## 实现陷阱

不同框架 bool mask 的 True 含义相反，有的接受 0/1 keep mask，有的接受 additive bias。把 0/1 直接加到 logits 只产生一分的偏置，并没有屏蔽。FP16 中使用一个不够负的常数，softmax 后可能仍有微小泄漏；使用 \(-\infty\) 又要处理全 mask 行。融合 SDPA/Flash kernel 的 is_causal 与自定义 mask 同时设置时，需确认是否支持组合及对齐方式。

## 验证

构造极小序列，用可辨认的 V（如单位向量）手算输出；断言被屏蔽概率为 0。做扰动测试：改变 PAD、未来段或另一 segment 的 token，目标输出不应变化。独立样本 packed 与单独前向应接近。

面试回答要将三种 mask 解释为不同维度的约束，给出可见性逻辑和广播 shape，并强调 position reset、label ignore 都不能替代 attention block mask。
