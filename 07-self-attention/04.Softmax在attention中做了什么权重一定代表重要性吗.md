# 04. Softmax 在 attention 中做了什么，权重一定代表重要性吗？

## 作用

对每个 query 的 score 行 \(s\)，softmax 产生

\[
a_j=\frac{\exp(s_j)}{\sum_k\exp(s_k)},
\]

使可见 key 权重非负、和为 1，再用 \(o=\sum_j a_jv_j\) 做凸组合。它提供竞争：提高某个 key 的 logit 不仅增加自身权重，也会通过分母降低其他权重；对 score 加相同常数不改变结果。

Softmax 并非唯一归一化选择，但它可微、与指数族概率形式兼容，并能通过 logit 尺度控制稀疏程度。Logits 大时分布尖锐，小且接近时趋于均匀。Mask 通常在 softmax 前把不可见位置设为 \(-\infty\) 或足够负值。

## 权重不等于完整重要性

Attention 权重只说明某层某头、某个前向输入下 V 的加权系数，不直接等于输入 token 对最终预测的因果贡献。原因包括：V 向量内容和范数不同，相同权重传递的信息量不同；多头、输出投影、残差和后续层会重组；不同 attention 分布可能产生相近 \(AV\)；改变 token 还会同时改变 Q、K、V，不是固定权重下删一项。

例如 token A 权重 0.6 但其 V 经输出投影落在无关方向，token B 权重 0.2 却提供决定性特征，不能据数字直接排序“重要性”。

## 分析方法

Attention map 可用于调试 mask、观察局部模式和提出假设，但解释应结合梯度/归因、输入干预、attention rollout 或消融，并承认各方法也有假设。若要证明因果作用，应替换/遮蔽 token 或干预 attention，再看输出变化，而非只画热力图。

## 数值细节

实现要先减行最大值，避免 exp 溢出；全 mask 行会得到 \(0/0\) 或 NaN，需要定义安全行为。Dropout 若加在 softmax 权重上，训练时权重和在单次样本中可能不再恰好为 1。

面试回答应先解释竞争归一化，再明确“attention is not explanation”的层级、V 与残差原因，同时保留它作为诊断信号的合理价值。
