# 05. Self-attention 与 cross-attention 有什么区别？

## 来源不同

Self-attention 的 Q、K、V 都来自同一序列表示 \(X\)：

\[
Q=XW_Q,\quad K=XW_K,\quad V=XW_V.
\]

它让序列内部 token 交换信息。Cross-attention 的 Q 来自查询/目标序列 \(Y\)，K、V 来自源/记忆序列 \(X\)：

\[
Q=YW_Q,\quad K=XW_K,\quad V=XW_V.
\]

它让一个序列读取另一个序列，例如 decoder 读取 encoder 输出，文本 token 读取图像特征。

## 形状与 mask

Self-attention 常有 \(L_q=L_k=L\)，score 是方阵；cross-attention 可有不同长度，score 为 \([L_y,L_x]\)。Decoder causal self-attention 要屏蔽未来目标 token，cross-attention 通常可看完整 source，只需 source padding/结构 mask；若流式源或对齐约束，则可能另加 mask。

位置坐标也不同。Self-attention 中相对距离 \(i-j\) 有自然含义；cross-attention 两侧可能是不同语言、模态或时间轴，不能直接减索引，除非任务定义了共同坐标。两侧通常先在各自编码器注入位置，再由内容匹配。

## 参数与缓存边界

两类 attention 可用相同数学 kernel，但投影参数通常独立。Encoder-decoder 每层可能先做 causal self-attention，再 cross-attention，再 FFN。Cross K/V 对固定 source 可复用计算，但本题重点是来源与可见性，不展开缓存实现。

## 常见误区

“Self”不表示 token 只看自己，而是 Q/K/V 来自同一集合；是否能看未来由 mask 决定。Cross-attention 也不等于必须两个不同模型，单模型中两个 hidden-state 集合即可。Decoder-only 把提示和回答拼一条序列，用 causal self-attention也能实现条件生成，并不一定含 cross-attention 模块。

面试回答应从 Q/K/V 来源、\(L_q\times L_k\) 形状、mask 与坐标系四方面比较，并举 encoder-decoder 或多模态例子。
