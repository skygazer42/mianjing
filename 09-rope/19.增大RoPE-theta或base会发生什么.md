# 19. 增大 RoPE theta/base 会发生什么？

## 结论

在常见定义 `inv_freq = base^{-2i/d_r}` 中，增大 base 会让除第一个维对外的频率变小、周期变长，使相同位置距离产生更慢的旋转，通常把部分表示能力移向更长尺度。但它不是无条件的“上下文长度旋钮”，会改变训练时形成的频谱匹配，直接修改已有模型可能造成短程或整体质量下降。

## 频率变化

\[
\theta_i=b^{-2i/d_r},\qquad T_i=\frac{2\pi}{\theta_i}.
\]

当 \(i=0\) 时 \(\theta_0=1\)，与 base 无关；\(i\) 越大，增大 \(b\) 对 \(\theta_i\) 的降低越明显。因此它是一种非均匀缩放：保留最高频，拉长低频，类似 NTK-aware 方法使用的频谱重分布。口语中有时把 `rope_theta` 称 base，也有人把 \(\theta_i\) 称频率，需先统一符号避免“增大 theta 让角度变大/变小”的歧义。

## 具体例子

若 base 从 10000 增到更大值，后部维对在 10k token 距离上的相位转数减少，更不易快速绕圈；但中前部维的相位也与训练时不同。模型 Q/K 投影可能已学会把某类语义放到特定频率通道，改变 base 相当于改变这些通道的距离响应。

## 工程取舍

从头训练时可把更大 base 与目标长度数据联合设计；已有模型扩展时通常使用有明确配方的 scaling，并配长序列继续训练，而非盲目试大数。base 还影响 cos/sin cache，不同请求或 prefix cache 不能混用不同配置。

## 面试回答要点

给出 inv_freq 公式，指出最高频不变、低频更慢和短程分布可能改变。常见错误是声称 base 等于最大位置，或 base 增大多少倍就保证上下文也精确增大多少倍。
