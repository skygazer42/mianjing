# 14. NTK-aware RoPE scaling 的直觉与公式是什么？

## 结论

NTK-aware scaling 的核心直觉是不要像线性插值那样把所有频率都同倍率变慢，而是尽量保留高频维的局部位置分辨率，更强地拉伸低频维以覆盖长距离。常见实现通过增大 RoPE base 重新分布整个频谱，名称来自对 Transformer neural tangent kernel 行为的分析与社区实践。

## 常见 base 变换

若原频率为 \(\theta_i=b^{-2i/d_r}\)，目标长度倍率为 \(s\)，一个常见静态公式是

\[
b'=b\,s^{d_r/(d_r-2)}.
\]

代入后，(i=0) 的最高频仍为 1；接近最后的最低频大约缩小 (s) 倍；中间频率获得平滑的不同缩放。这正体现“局部少改、长程多拉伸”。公式在不同库、模型和 partial rotary 配置中可能有修正，必须以 checkpoint 官方配置为准。

## 与 Position Interpolation 比较

PI 直接用 \(\theta_i/s\)，所有频段都压缩，目标范围映射明确但近距离分辨率下降。NTK-aware 不保证每个频段都严格落回原相位范围，却更保留高频局部结构，零样本或少量微调时常有更好的短程表现。它仍会改变频谱，不能保证不经训练就保持所有任务质量。

## 工程细节

base 变换必须用 rotary dimension (d_r)，不能误用模型宽度；当 (d_r=2) 时上述指数无定义，也说明公式有适用条件。计算新的 inv_freq 后，所有位置的 Q/K 和历史缓存必须共享同一套频率。静态 scaling 在短序列也使用新 base，可能产生短上下文回归，因此出现了动态与分频段变体。

## 面试回答要点

先讲“高频保局部、低频扩长程”，再给 base 变换作为一种常见实现，并明确它不是统一标准。不要把 NTK-aware 等同于增加 `max_position_embeddings`，后者只改容量声明。
