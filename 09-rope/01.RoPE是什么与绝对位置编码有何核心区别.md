# 01. RoPE 是什么，与绝对位置编码有何核心区别？

## 结论

RoPE 是一种把位置写进注意力几何关系的方法：它不把位置向量直接加到 token embedding，而是按位置对每个 attention head 的 Q、K 成对维度做旋转。这样 Q 与 K 的点积会显式依赖二者的相对位移，同时各位置旋转保持向量范数。它由 RoFormer 工作系统提出，后来广泛用于 decoder-only LLM。

## 核心原理

对第 (m) 个位置的向量 (x)，将每两个通道视为二维平面，施加旋转 (R(m\theta_i))：

\[
R(\phi)=\begin{bmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{bmatrix}.
\]

不同维度对使用不同频率 \(\theta_i\)。attention 使用 \(R_mq_m\) 与 \(R_nk_n\) 点积，由旋转矩阵的正交性可把位置项合并成 \(R_{n-m}\)，因此分数与相对距离相关。

## 与绝对位置相加的区别

绝对位置 embedding 通常形成 (x_m=e_m+p_m)，位置在进入每层前已经与内容相加，模型需要自行从点积中学会相对关系；learned absolute embedding 还没有训练长度外的新行。RoPE 在每层 Q/K 上直接改变相位，不额外增加位置表参数，并可计算任意整数位置的 sin/cos。但“公式能算到任意位置”不等于模型能可靠外推，超训练长度仍会遇到频率分布外移和注意力模式失配。

## 具体例子

同一个词出现在位置 3 与位置 8，内容投影相同，但旋转角不同。若另一个 key 与它们分别相距 2 和 7，点积感受到的是不同相位差，而不是只知道两个绝对编号。这种相对结构很适合自回归模型在每步追加位置。

## 常见误区与面试要点

RoPE 不是把 Q/K 乘一个标量，也不是普通 sinusoidal embedding 的同义词；它使用同类正弦频率，但作用方式是旋转。回答时应说清“作用对象、二维旋转、相对点积、无额外位置表、外推仍有限”五点。
