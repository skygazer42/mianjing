# 26. RoPE 如何扩展到二维图像与多模态位置？

## 结论

一维 RoPE 用 token 序号产生相位；图像 patch 具有行、列两个坐标，多模态还可能有时间轴。扩展思路是把 head 的 rotary 通道分组，分别用 (x)、(y)、(t) 坐标生成旋转，使点积依赖各轴相对位移，而不是把二维网格粗暴展平后只看一维距离。

## 二维轴向 RoPE

将 rotary 子空间拆成两部分：

\[
q'=[R_{x}(q_x);R_{y}(q_y)],\qquad
k'=[R_{x'}(k_x);R_{y'}(k_y)].
\]

点积含 (R_{x'-x}) 与 (R_{y'-y})，因此横向和纵向位移分开表达。网格中 `(row=0,col=3)` 与 `(row=1,col=0)` 即使展平索引相近/相同差值，二维相对关系也不会混淆。通道在各轴如何分配是模型设计的一部分。

## 多模态位置

视频可增加时间轴；文本 token 通常仍沿一维序列递增。多模态 RoPE 可为视觉 token 使用时间/高/宽三组位置，为文本 token 采用协调的轴位置，并在模态连接处维护后续文本 offset。不同模型对坐标压缩、patch merge 后位置、文本三轴填充值定义不同，必须跟随官方 processor 与模型实现。

## 工程陷阱

图像 resize、动态分辨率、patch merge 会改变网格尺寸，position ids 应从实际网格生成，而非原像素坐标。KV cache decode 新文本位置必须接在多模态前缀的逻辑位置规则之后。轴向维数需为偶数且总和不超过 head dim；fused RoPE 内核若只支持一维连续位置可能需要专用实现。

## 面试回答要点

用“通道分轴 + 每轴相对旋转”解释 2D/3D RoPE，再指出展平一维会丢空间归纳偏置。不要假定所有视觉模型都用相同的 M-RoPE；有些采用二维绝对 embedding、相对 bias 或其他位置机制。
