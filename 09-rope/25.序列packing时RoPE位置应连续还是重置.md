# 25. 序列 packing 时 RoPE 位置应连续还是重置？

## 结论

packing 把多条短样本拼进一个物理序列以减少 padding。不同文档间必须用 block-diagonal/segment mask 隔离；RoPE position 是连续还是每段重置，取决于训练定义。若各样本本应独立，通常每段从 0 重置更接近未 packing 的结果；若训练目标把它们视为一个连续 token 流，则可连续编号。

## 独立样本语义

假设样本 A 长 3、B 长 2，拼成 `[A0,A1,A2,B0,B1]`。独立语义下 position ids 为 `[0,1,2,0,1]`，attention mask 还要阻止 B 关注 A，也阻止 A 关注 B。仅重置 position 而不隔离 attention 不够：相同位置相位不会阻止跨文档内容泄漏。

重置的好处是 B 的 logits 与它单独作为长度 2 样本运行更容易对齐，也避免后部短文档总处在大位置上。但如果预训练本来使用 EOS 连接文档并允许跨文档 causal attention，强行隔离/重置会改变数据分布，未必正确。

## 工程实现

需要 segment ids、每段 offset 与有效长度，fused attention 可用 cumulative sequence lengths（cu_seqlens）直接表示多个独立序列，不必物化方阵 mask。position id 可由“全局索引减去本段起点”得到。分布式 sequence parallel 切分后仍需保留全局段元数据，防止边界落在不同 rank 时重置错位。

## 与推理的关系

训练 packing 不等于推理 prefix 拼接。推理中 system prompt、user prompt 与 answer 通常是同一对话序列，应连续编号并允许后部读取前缀；把每个消息角色都重置会破坏 checkpoint 预期。

## 面试回答要点

不要给无条件的“必须重置”。先问 packed 单元是否独立，再同步决定 segment attention 与 position。核心原则是与未 packing 的目标函数和模型训练约定保持函数等价。
