# 03. 为什么 RoPE 的注意力点积只依赖相对位置？

## 结论

关键是旋转矩阵满足 (R(a)^TR(b)=R(b-a))。把位置 (m) 的 query 旋转为 (R(m\theta)q)，位置 (n) 的 key 旋转为 (R(n\theta)k)，二者点积中的两个绝对角会相消，只留下角度差 ((n-m)\theta)。这就是 RoPE 的相对位置性质。

## 推导

对一个二维频率块：

\[
\langle R(m\theta)q,R(n\theta)k\rangle
=q^TR(m\theta)^TR(n\theta)k
=q^TR((n-m)\theta)k.
\]

高维 RoPE 只是多个频率块的和，所以每一项都只含 (n-m)。若同时把两个位置平移常数 (c)，差值不变，点积也不变。这是“相对位置进入 attention score”的严格含义，不是说旋转后的单个 Q 表示本身只含相对位置；单个 (R_mq) 仍依赖绝对 (m)。

## 展开直觉

二维展开可得到内容相关的两项：

\[
(q_0k_0+q_1k_1)\cos\Delta+(q_0k_1-q_1k_0)\sin\Delta,
\]

其中 (Delta=(n-m)\theta)。距离通过 sin/cos 调制内容匹配，既不是单纯给距离加一个固定 bias，也不保证距离越远分数单调越小；实际衰减是多频率、内容向量与训练共同形成的统计效果。

## 边界与误区

因果 mask 仍然必须存在：相对点积不会自动禁止关注未来。多频率相位具有周期性，不同距离可能在某些频段接近，但所有频段组合可提供更丰富的区分。若 Q 与 K 使用不同 position id、不同 base 或不同维度配对，上述相消关系就会被破坏。

## 面试回答要点

写出 (R_m^TR_n=R_{n-m}) 即抓住本质，再解释“分数相对、单向量仍绝对”和“不等于单调距离惩罚”。延伸追问可讨论为什么共同旋转 V 对 attention 权重的相对性质没有必要。
