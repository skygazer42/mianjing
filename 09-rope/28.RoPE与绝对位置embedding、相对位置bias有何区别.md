# 28. RoPE 与绝对位置 embedding、相对位置 bias 有何区别？

## 结论

三者主要区别是位置注入点。绝对位置 embedding 在进入 Transformer 时与 token 表示相加；相对位置 bias 在每层 attention logits 上加一个由距离决定的标量；RoPE 在点积之前按位置旋转 Q/K。它们都能提供顺序，但参数化、相对归纳偏置、长上下文和内核成本不同。

## 形式比较

绝对位置：(h_m=e_m+p_m)。若 (p_m) 是 learned table，参数随最大长度增长，表外位置未训练；固定 sinusoidal 可计算表外位置，但相对关系需要网络从加法交叉项中利用。

相对 bias：

\[
s_{mn}=q_m^Tk_n/\sqrt{d_h}+b_{bucket(n-m),h}.
\]

T5 类方法可把距离分桶，近距离细、远距离粗；bias 与内容无关但直接控制每个 head 的距离偏好。

RoPE：

\[
s_{mn}=(R_mq_m)^T(R_nk_n)/\sqrt{d_h},
\]

距离与内容通过 sin/cos 交叉耦合，无 learned 位置表；每个维对提供不同频率。

## 工程取舍

绝对 embedding 最直观、一次相加即可，但扩表麻烦；relative bias 需要 attention kernel 支持额外 bias 或现场生成，分桶可外推但远距离分辨率受限；RoPE 易与常见 fused attention 配合，只需预旋转 Q/K，但 layout、base 与 scaling 配置兼容复杂。某些模型会组合绝对/相对机制，不能假定互斥。

## 评估与误区

位置机制不改变 causal mask 的必要性，也不直接降低 attention 复杂度。比较时应控制模型、数据、参数与训练 token，不宜仅用一个长度的 PPL 下结论。

## 面试回答要点

建议画出数据流：`embedding 加法`、`QK 前旋转`、`logits 后加 bias`。注入位置一明确，参数量、cache 方式与外推差异就容易顺着推导出来。
