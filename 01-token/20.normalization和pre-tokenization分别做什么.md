# 20. tokenizer 里的 normalization 和 pre-tokenization 分别在做什么？为什么重要？

## 回答

normalization 在模型编码前统一文本形式，例如 Unicode 规范化、全半角转换、大小写处理、空白符处理或重音符号处理。它减少了同一语义的多种写法，但某些操作会损失原始信息。

pre-tokenization 则先按较粗的边界切开文本，例如识别空格、标点、数字、代码符号或特殊模式，再交给 BPE、WordPiece 等子词算法细分。它决定哪些字符可以跨边界合并。

二者会影响 token 数、ID、可逆性和模型行为。训练、评估、索引与在线推理若不一致，即使原始文本相同，也可能产生不同输入序列。

## 面试要点

normalization 解决“文本先变成什么样”，pre-tokenization 解决“先按哪些边界拆”；两者都属于 tokenizer 契约的一部分。
