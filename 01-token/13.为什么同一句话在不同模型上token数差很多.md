# 13. 为什么同一个句子在 GPT、BERT、LLaMA 这类模型上的 token 数可能差很多？

## 回答

不同模型配套的 tokenizer 不同。它们可能使用 Byte-level BPE、WordPiece、SentencePiece BPE 或 Unigram，也会在词表大小、训练语料、Unicode 规范化、空格保留、大小写处理和特殊 token 规则上不同。

例如有的 tokenizer 把前导空格与英文词绑定，有的把中文按字符或更长片段处理；有的以字节为初始单位，有的依赖字符或预切分后的词。因此同一句话即使语义完全相同，得到的 token 边界和数量也会不同。

## 面试要点

比较 token 数、上下文是否超限或 API 成本时，必须使用目标模型的 tokenizer；不能把另一模型的统计结果直接套用。
