# 25. 代码模型的 tokenizer 和通用文本 tokenizer，设计重点有什么不同？

## 回答

通用文本 tokenizer 更关注自然语言词、子词、多语言覆盖和常见标点；代码 tokenizer 则要额外重视关键字、运算符、括号、缩进、换行、路径、版本号、正则、字符串转义和变量命名风格。

代码中的标识符几乎无限，例如 `get_user_profile_by_token`、`camelCase`、UUID 和哈希。好的代码 tokenizer 既要避免把常见代码片段切得过碎，也必须对罕见标识符和任意字节串有可靠回退能力。

## 面试要点

代码 tokenizer 的目标不只是压缩 token 数，还要尽量保留语法边界和格式信息；训练语料应覆盖目标语言、框架和真实仓库中的格式习惯。
