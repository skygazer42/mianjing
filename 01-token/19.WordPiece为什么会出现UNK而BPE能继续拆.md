# 19. WordPiece 为什么会出现 `[UNK]`，而 BPE 往往还能继续拆？

## 回答

经典 WordPiece 的编码依赖词表中是否存在从当前位置开始的合法子词；如果某段文本无法完整分解为这些子词，常用一个 `[UNK]` 代替整段或整词。

许多 BPE 实现则以字符或字节作为基础单位，尤其是 byte-level BPE：任意 Unicode 文本都能先表示为字节，再按合并规则编码，因此通常能继续拆下去而不是产生未知词。

## 面试要点

这是常见实现差异而非绝对规律。WordPiece 也可以设计回退机制，BPE 若基础字符覆盖不完整也可能出现未知符号；应以具体 tokenizer 配置为准。



关键点是：**这不是 WordPiece 与 BPE 必然存在的区别，而是经典 WordPiece 和 byte-level BPE 的词表覆盖方式及失败策略不同。**

## WordPiece 为什么产生 `[UNK]`

经典 BERT 风格 WordPiece 通常先把文本预切成“词”，再要求用词表中的 token **完整覆盖整个词**。

其切分逻辑通常是最长匹配：

1. 从词的开头寻找词表中最长的匹配片段。
2. 后续片段通常必须匹配带有 `##` 标记的 token。
3. 如果任何位置找不到可用片段，整个词的切分失败。
4. 输出一个 `[UNK]`，而不是保留已匹配的部分。

举一个纯概念示例。假设要切分：

```text
abx
```

词表中只有：

```text
a
##b
```

没有：

```text
##x
```

WordPiece 可以匹配 `a` 和 `##b`，但不能完整覆盖最后的 `x`，所以经典实现通常输出：

```text
[UNK]
```

而不是：

```text
a  ##b  [UNK]
```

这样设计能让“一个预切分单词要么被完全解析，要么整体未知”的行为保持简单一致，但代价是会丢失已经能够识别的部分。

此外，经典实现还可能因为以下原因产生 `[UNK]`：

* 某个字符完全不在词表中
* 缺少对应位置的 continuation token
* 一个预切分单词超过实现规定的最大字符数
* 文本规范化后仍包含无法覆盖的字符

## BPE 为什么常能继续拆

BPE 从基础符号开始，然后只学习“合并规则”。

```text
基础字符或字节
    ↓
合并高频相邻片段
    ↓
得到较长 token
```

合并只是一种压缩：如果某个较长片段不能合并，BPE 可以退回到更小的基础单位。

例如，已知合并规则只能把 `a` 和 `b` 合并：

```text
a + b → ab
```

对于 `abx`，BPE 可以得到：

```text
ab  x
```

如果没有 `ab` 的合并规则，也可以继续保留：

```text
a  b  x
```

前提是 `a`、`b`、`x` 都属于基础符号集合。

## 真正避免 `[UNK]` 的是 byte-level 覆盖

普通字符级 BPE也可能产生未知字符。假设它的基础字符集中没有某个罕见汉字或 emoji，它同样无法正常表示该字符。

byte-level BPE 则先把输入转换为 UTF-8 字节。所有输入最终都由 256 种字节值组成，因此只要完整保留这些基础字节，就能编码任意有效文本：

```text
任意字符
  ↓ UTF-8
有限的字节序列
  ↓ BPE 合并
一个或多个 token
```

不能合成长 token 时，它就退回更小的字节 token，因此通常不需要 `[UNK]`。

所以更准确的比较是：

| tokenizer         | 基础覆盖      | 遇到无法完整匹配的输入                      |
| ----------------- | --------- | -------------------------------- |
| 经典 BERT WordPiece | 有限字符和子词词表 | 整个预切分词变成 `[UNK]`                 |
| 字符级 BPE           | 已配置的基础字符集 | 未覆盖字符仍可能变成未知 token               |
| Byte-level BPE    | 全部字节      | 退回字节 token，通常没有 `[UNK]`          |
| SentencePiece     | 取决于配置     | 未启用 byte fallback 时也可能产生未知 token |

因此，“BPE 能继续拆”的根本原因通常是：

1. BPE 的合并过程保留了基础符号；
2. 无法合并时可以退回更小单位；
3. 如果基础单位是字节，就能覆盖任意输入。

而经典 WordPiece 没有通用字节回退，并且要求词表中的子词完整覆盖一个预切分单词，所以匹配失败时会输出 `[UNK]`。
