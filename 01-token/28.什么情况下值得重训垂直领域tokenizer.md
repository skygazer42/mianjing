# 28. 什么情况下值得为垂直领域重新训练 tokenizer？

## 回答

当领域语料规模足够大、输入长期稳定且现有 tokenizer 对高频术语切分严重碎片化时，重训 tokenizer 才可能值得。例如生物序列、化学表示、专利编号、特定编程语言或大量内部 DSL 占据模型输入的主要部分。

还需要具备继续预训练或从头训练的预算，因为新 tokenizer 改变了 token ID 语义，embedding 和输出层不能简单沿用。若只是少量新名词或低频缩写，RAG、词典规范化、提示词和领域微调通常更经济。

## 面试要点

先量化问题：统计领域文本的 token 膨胀、关键术语碎片率和端到端成本；只有收益能覆盖兼容性和重训成本时才改 tokenizer。
