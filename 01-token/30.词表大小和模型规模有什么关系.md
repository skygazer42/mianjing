# 30. tokenizer 的词表大小和模型规模之间通常是什么关系？为什么不能无脑把词表做得特别大？

## 回答

词表大小为 `V`、隐藏维度为 `D` 时，输入 embedding 参数量约为 `V × D`；若输出层不共享权重，softmax 输出层也会带来同量级参数。更大的词表能让高频词和片段更完整，降低序列长度，但会显著增加参数、显存和训练成本。

词表过大还会让大量低频 token 缺少训练样本，导致其 embedding 和输出概率学习不充分；输出分类空间也更大。词表过小则会使文本过度碎片化，增加 attention、上下文和推理成本。

## 面试要点

模型越大通常有能力承载更大的词表，但不存在固定比例。词表大小应结合模型参数、训练 token 总量、语言与代码覆盖、序列长度和部署成本共同选择。
