# 23. 为什么英文、中文、阿拉伯语在同一个模型里的 token 成本可能差很多？

## 回答

同一个 tokenizer 对不同语言的覆盖并不均衡。词表更多来自哪类训练语料，哪类文字、常见词和空格模式就更可能被编码为较长、较少的 token；覆盖较弱的语言则会被拆成更多字符或字节片段。

英文有明显空格边界且在很多通用语料中占比高；中文没有空格；阿拉伯语还涉及连写、形态变化和 Unicode 表示等因素。结果是相同语义长度的内容可能占用不同 token 数，进而影响上下文可用长度、延迟和按 token 计费的成本。

## 面试要点

应对真实目标语言的样本做 token 统计，不能只用英文基准估算多语言产品的容量与价格。
