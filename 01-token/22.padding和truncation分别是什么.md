# 22. padding 和 truncation 分别是什么？为什么对 batch 训练和推理很重要？

## 回答

padding 是把较短序列补到统一长度，通常填入 `<pad>`；这样同一 batch 可以组成规则张量并行计算。attention mask 与 loss mask 必须标记这些补齐位置，避免模型把它们当成真实内容或对其计算损失。

truncation 是当输入超过最大长度时按策略截断，例如保留开头、结尾、两侧或滑动窗口。它防止序列超过模型上下文窗口和显存预算，但也可能截掉关键信息。

## 面试要点

动态 padding 可以减少无效计算；生成任务还要为输出预留 token。截断策略需要和任务匹配，例如分类常保留两端，长文问答常采用分块或检索，而不是简单截断。
