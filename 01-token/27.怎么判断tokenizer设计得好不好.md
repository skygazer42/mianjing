# 27. 怎么判断一个 tokenizer 设计得好不好？你会看哪些指标？

## 回答

需要同时看编码效率、覆盖能力和下游效果，而不是只看词表大小。

- 压缩率或 fertility：每个词、字符或字节平均产生多少 token；目标语料越少通常越省上下文。
- 覆盖与回退：`<unk>` 比率、罕见字符/emoji/代码/多语言的编码稳定性，以及是否可逆。
- 运行效率：训练和编码速度、内存占用、并发性能。
- 下游表现：在检索、分类、生成、代码补全等真实任务上的质量、长度和成本。
- 公平性：不同语言、领域和格式是否出现明显的 token 膨胀。

## 面试要点

应在与生产接近的语料上做 A/B 测试；平均 token 更少不一定更好，过大的词表可能增加模型参数并稀释训练样本。
