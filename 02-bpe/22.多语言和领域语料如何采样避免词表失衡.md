# 22. 多语言和领域语料如何采样，避免 BPE 词表失衡？

## 结论

BPE 完全由频次驱动，直接混合原始语料会让高资源语言或重复模板占据多数 merge。应按预期流量与公平目标做语言/领域分层采样，常用温度平滑、上限截断、去重和质量权重，并用分组 token 效率而非整体平均数检查结果。

## 采样方法

若语言 \(i\) 的原始占比为 \(p_i\)，可用

\[
q_i=\frac{p_i^\alpha}{\sum_j p_j^\alpha},\quad 0<\alpha<1
\]

平滑高低资源差距。再在语言内部按网页、对话、代码、专业文档分层。完全按均匀语言采样会过度提升极小语种并偏离线上分布，完全按流量采样又可能产生严重不公平，因此 \(\alpha\) 和最低/最高配额需通过业务目标选择。

## 具体例子

英文占 90%、中文 9%、某低资源语言 1% 时，直接训练可能让英文常见整词获得大量 merge，而低资源语言退化为 bytes。温度采样可提高后两者权重；同时对英文导航栏、版权页和日志模板去重，否则无意义模板仍会污染词表。医学域若只占总体 0.1%，可单设配额，但要验证其术语 token 是否真的带来下游收益。

## 工程取舍与误区

采样单位应明确是文档、字符、UTF-8 字节还是预分词 token；按文档数会被文档长度欺骗。语言识别器的错误也会污染分组统计。评估应按语言报告 chars/token 或 bytes/token、P95 序列长度、fallback 比例及词表占用，外加混合脚本和代码样本。不能通过观察 token 字符串“属于哪种语言”简单分配所有权，因为许多数字、标点和词根跨域共享。

## 面试回答要点

- 频次算法天然放大原始数据不平衡。
- 温度采样公式、去重与领域配额是三项常见措施。
- 整体压缩率可能掩盖低资源语言灾难，必须分组看尾部。
- 最终采样要接近部署需求，也要满足质量与公平约束。
