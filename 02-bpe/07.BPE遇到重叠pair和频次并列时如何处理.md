# 07. BPE 遇到重叠 pair 和频次并列时如何处理？

## 结论

重叠 pair 必须按确定规则选择不相交位置，通常是从左到右贪心替换；最高频 pair 并列时也必须有稳定的 tie-break，例如按基础符号 ID、首次出现位置或字典序选择。两类规则都会改变后续语料状态，因而属于 tokenizer 可复现性的一部分。

## 重叠问题

序列 A A A 中，pair \((A,A)\) 出现在位置 (0,1) 与 (1,2)，但它们共享索引 1。一次并行替换不能同时消费同一个符号。若采用左到右规则，结果为 AA A；下一轮才可能继续处理新邻接。实现上扫描指针 i：匹配时输出新 token 并令 \(i\leftarrow i+2\)，否则输出原 token 并令 \(i\leftarrow i+1\)。

## 并列问题

设 \((a,b)\) 与 \((c,d)\) 都出现 100 次。先合并哪一个可能改变另一对的次数、创建 token 的 ID 和全部后续 rank。算法论文常只写 argmax，却没有规定工程 tie-break；因此复现某实现时要遵循它的排序和遍历约定，而不能认为所有最高频选择都等价。分布式训练还应在汇总后统一决策，而非各 worker 自行选取。

## 工程取舍与常见误区

用无序哈希表的迭代次序解并列，会让相同语料在不同进程得到不同 merges。浮点采样权重还可能因归约顺序产生微小误差，最好使用整数计数或定义二级排序键。增量算法删除位置后必须检查节点版本，避免优先队列里陈旧条目重复合并。常见误区是把重叠 pair 的“出现次数统计”和“本轮可同时替换次数”混为一谈：训练评分通常统计两个相邻位置，但实际替换必须不重叠。

## 面试回答要点

- 用 AAA 例子明确说明不能同时产生两个 AA。
- tie-break 不一定影响算法类别，却影响确定的词表、ID 和线上兼容。
- 单测应覆盖 AAAA、边界标记、并列频次和多线程重复运行。
- 保存训练器版本、排序规则与随机种子，才能真正复现产物。
