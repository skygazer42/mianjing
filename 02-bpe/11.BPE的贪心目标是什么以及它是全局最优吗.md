# 11. BPE 的贪心目标是什么，以及它是全局最优吗？

## 结论

标准 NLP BPE 每轮选择当前加权频次最高的相邻 pair，目标可以直观理解为让本轮替换获得最大的 token 数减少。它是局部贪心启发式，不直接最大化语言模型似然，也不保证在给定词表大小下得到全局最短序列或最佳下游效果。

## 公式与解释

当前语料共有 \(N\) 个符号，若 pair \((a,b)\) 的可替换出现次数为 \(C(a,b)\)，一次不重叠替换大致令长度减少 \(C(a,b)\)。于是选择

\[
(a^\*,b^\*)=\arg\max_{(a,b)}C(a,b)
\]

能最大化这一轮的长度下降。但合并会创造和摧毁邻接关系，今天的选择会改变以后候选空间；若先选第二高频 pair，后续若干轮可能获得更好的总结果，标准 BPE 不回溯也不搜索这种组合。

## 具体例子

假设某高频边界 pair 出现 100 次，但合并后不再能与左右片段形成有价值的长 token；另一 pair 出现 90 次，却是多个高频词根的公共起点，连续两轮可产生更大收益。贪心算法仍会先选 100 次者。并列频次的选择也可能沿着不同路径生成不同词表，说明目标并非唯一全局解。

## 工程取舍与常见误区

贪心的优点是定义简单、训练结果易解释、编码确定且实现可扩展；缺点是对语料频率和预分词很敏感。有人把 BPE 的最高频评分描述成“概率最大”或“语言模型损失最小”，这是把它与 WordPiece/Unigram 混淆。真正选择 tokenizer 时，应在固定词表预算上比较压缩率、长尾公平性、下游质量和吞吐，而不是用训练目标替代最终评估。

## 面试回答要点

- 说清局部目标是当前 pair 频次或长度下降。
- 说明选择会改变后续邻接，因而没有全局最优保证。
- 贪心不是缺陷的同义词，它换来了规模化和确定性。
- 可追问：能否用 MDL、下游 loss 或带惩罚目标重新设计 merge 评分？
