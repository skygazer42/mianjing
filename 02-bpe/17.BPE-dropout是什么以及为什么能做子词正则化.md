# 17. BPE-dropout 是什么，以及为什么能做子词正则化？

## 结论

BPE-dropout 在训练下游模型时，以一定概率暂时跳过可用 merge，让同一字符串产生更细或不同的合法分词。它不必修改固定词表和 token ID，却向模型暴露多种子词组合，可降低对单一切分的过拟合，尤其有利于低资源、形态丰富语言和噪声输入。

## 核心原理

普通 BPE 对给定文本和模型文件是确定性的。加入 dropout 后，在某次编码中将部分候选 merge 屏蔽，再在剩余规则上继续按 rank 合并。概率 \(p=0\) 退化为标准 BPE；\(p\) 越大，平均 token 越细、序列越长。它类似数据增强：模型需要从不同边界组合中学习稳定表示，而不是把某个整块 token 当作唯一记忆单元。

## 具体例子

标准分词可能把 “playing” 编为 [play, ing]。一次随机编码跳过 play 的构造 merge 后，可能得到 [p, lay, ing]；另一次跳过 ing 相关 merge，可能得到 [play, i, ng]。这些 token 都已在固定 BPE 词表中，因此 embedding 维度不变。推理通常关闭 dropout，使用确定性最优编码，以保证可复现、缓存命中和稳定时延。

## 工程取舍与常见误区

dropout 过高会显著拉长序列，改变训练 token 预算，并让罕见基础 byte 获得过多噪声梯度。应记录随机种子，区分 tokenizer worker 的随机流，并以实际 token 数而非句子数控制 batch。它不是把 token ID 随机丢成 mask，也不是在 merge 训练阶段随意删除规则。对线上鲁棒性要用拼写扰动、领域长尾和标准集联合验证。

## 面试回答要点

- 固定词表、随机应用 merge、训练开推理关。
- 作用是子词级数据增强和边界鲁棒性。
- 代价是序列增长、吞吐下降与复现实验更复杂。
- 与 Unigram sampling 比较：前者扰动合并过程，后者从概率 lattice 采样路径。

## 延伸追问

实验应固定实际训练 token 数，因为 dropout 让同样句子产生更多 token；若只固定 epoch，大 dropout 组会得到更多优化步内 token，比较并不公平。还要检查跳过 merge 后产生的细粒度 token 是否都得到足够梯度，并报告多个随机种子的均值与方差。
