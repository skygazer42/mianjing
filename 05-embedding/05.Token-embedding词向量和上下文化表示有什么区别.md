# 05. Token embedding、词向量和上下文化表示有什么区别？

## 三个层次

Token embedding 通常指模型输入表 \(E[token\_id]\) 的静态行：同一个 id 在任何句子里起点相同。传统词向量常指 Word2Vec、GloVe 等为“词”学习的静态向量，粒度可能与现代子词 token 不同。上下文化表示则是 token embedding 加入位置等信息、经过多层注意力与前馈网络后的隐藏状态；它依赖整段上下文和所在层。

例如“苹果发布新手机”和“吃一个苹果”若 tokenizer 中“苹果”对应相同 id，其输入行相同；经过 Transformer 后，前者会吸收“发布、手机”的信息，后者吸收“吃、一个”的信息，最终隐藏状态不同。子词模型中一个词还可能由多个 token 构成，完整词或句子的向量需要聚合多个隐藏状态，不能直接拿某一行代替。

## 数学视角

输入阶段可写成

\[
h_t^{(0)}=E[x_t]+P_t+\text{other features},
\]

第 \(l\) 层输出为

\[
h_t^{(l)}=F_l(h_1^{(l-1)},\ldots,h_L^{(l-1)}).
\]

\(E[x_t]\) 只取决于 id；\(h_t^{(l)}\) 取决于全序列、mask、位置、层号乃至模型模式。句向量模型通常对最后或若干层做 mean/CLS pooling，再通过对比学习使整体向量适合余弦相似度。

## 常见误区与选择

- “查 embedding 表就能做高质量语义检索”通常不成立，尤其对多义词、短语和句子。
- 上下文化表示也不是天然适合比较；只用语言模型隐藏状态做平均可能各向异性严重，需要专门训练或后处理。
- “词向量维度相同就能直接比较”是错的，不同模型坐标系可任意旋转，必须同源或显式对齐。
- 不同层捕获的信息不同：中间层可能更偏句法，末层更贴近训练输出目标，最佳层应通过任务验证。

回答时先区分“参数表的一行”和“网络针对当前上下文计算出的状态”，再说明 token/word 粒度差异、pooling 与任务训练。延伸追问通常是：为什么同一词多义能被消歧，以及如何把变长序列转成固定维句向量。
