# 03. 为什么训练后语义相近的 token embedding 往往更接近？

## 核心结论

语义相近并不是 embedding 的先验属性，而是训练任务、数据共现和参数共享共同塑造的结果。分布假设认为“出现在相似上下文中的词往往有相似用法”。当两个 token 为降低损失需要对相似上下文产生相似预测，它们接收到的梯度具有相关方向，长期训练后可能在某种相似度下靠近。

## 从目标函数理解

以简化的 skip-gram 为例，中心词向量 \(u_w\) 与上下文向量 \(v_c\) 通过 \(u_w^\top v_c\) 决定共现概率。最大化真实词对概率、压低负样本概率，会让拥有相似上下文集合的两个中心词形成相近的点积模式。矩阵分解视角下，这相当于用低秩向量近似词—上下文统计矩阵。语言模型更复杂，但输入 embedding 经多层网络参与预测；若替换两个 token 后所需行为相似，优化也可能复用相近方向。

例如“猫在沙发上睡觉”和“狗在地毯上睡觉”使“猫”“狗”与“睡觉、宠物环境”形成相似统计联系。不过“猫”和“狗”也会被区分，因为它们并非在所有上下文可互换。Embedding 邻近表达的是任务相关的可替换性或关联性，不等同于词典意义。

## 为什么并不总是成立

- 高频词受到更多更新，范数和公共主方向可能主导距离，出现各向异性。
- 反义词常处在相同句法环境，“好”和“坏”可能很近，但语义极性相反。
- 一词多义在静态 token 行中被混合；真正消歧通常发生在上下文化隐藏状态。
- 子词 embedding 表示片段而非完整词，单独比较可能没有语言学意义。
- 点积训练的模型未必在未经归一化的欧氏距离上表现最好。

## 如何验证

不能只展示几个最近邻。应根据用途做词相似度、类比、下游分类或检索评估，并与频率分桶、随机基线比较；还要分别检查输入表、最终层句向量以及归一化前后结果。若模型针对句级对比目标训练，句向量相似度通常比裸 token 表更有意义。

面试要点是：用“训练目标诱导的分布结构”解释，而不是说模型把人工语义直接写进向量；同时主动指出相似上下文、反义词、多义词与度量选择的边界。
