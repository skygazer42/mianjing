# 06. 为什么有些 Transformer 会缩放或归一化输入 embedding？

## 结论

输入 embedding 的尺度会影响它与位置编码、残差支路以及后续注意力 logit 的相对量级。有些 Transformer 将查表结果乘 \(\sqrt{d_{\text{model}}}\)，有些依赖 LayerNorm/RMSNorm，有些在 embedding 后直接归一化；这些并非可随意混搭的“固定规范”，而是与初始化、位置编码方式和网络归一化结构配套的尺度设计。

## 为什么乘 \(\sqrt d\)

经典 Transformer 的输入、输出权重共享，初始化后单个 embedding 分量的量级可能随 \(d\) 缩小，而固定正弦位置编码分量在 \([-1,1]\)。将 token embedding 乘 \(\sqrt d\) 能使内容信号与位置向量处于更合适的相对尺度。注意这与 attention score 除以 \(\sqrt{d_k}\) 是两个不同问题：前者调整输入表示，后者控制 QK 点积方差与 softmax 饱和。

若使用可学习位置向量、RoPE（在 Q/K 上旋转）或不同初始化，未必需要相同缩放。现代预归一化模型常通过 RMSNorm/LayerNorm稳定各层输入，但归一化并不能完全消除 embedding 初始尺度对残差路径和早期优化的影响。

## 归一化的影响

LayerNorm 会逐 token 去均值并按方差缩放，RMSNorm 只按均方根缩放；L2 归一化则把整条向量固定为单位范数，性质不同。对输入强制 L2 归一化可能丢掉模型利用范数编码置信度或频率的能力，并改变与残差相加的动态。句向量输出做 L2 归一化常用于余弦检索，不能据此推导输入表也应同样处理。

## 工程排查

迁移 checkpoint 时必须复现原模型的 embed_scale、embedding norm、位置注入和 dtype；漏乘或重复乘 \(\sqrt d\) 往往不会 shape 报错，却会显著降低困惑度表现。可以记录 embedding 输出 RMS、第一层 norm 前后 RMS、QK logit 标准差和梯度范数，判断是否尺度失衡。混合精度下过大尺度还可能放大溢出风险。

面试回答要指出：缩放的目的不是“增加语义”，而是匹配方差和信号比例；是否采用必须从完整架构与 checkpoint 约定判断，而不能机械套用经典公式。
