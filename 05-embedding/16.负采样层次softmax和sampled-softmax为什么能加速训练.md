# 16. 负采样、层次 softmax 和 sampled softmax 为什么能加速训练？

## 问题背景

词表为 \(V\) 时，full softmax 对每个训练样本都计算 \(V\) 个 logit，成本约 \(O(Vd)\)。在经典词向量或超大类别任务中，\(V\) 可达百万，真正标签却只有一个。三类方法都试图避免遍历整个词表，但优化目标和概率解释不同，不能互换名称。

## 三种思路

**负采样**把多分类改成若干二分类：拉高真实词对 \(u_w^\top v_c\)，从噪声分布抽 \(K\) 个负样本并压低其分数：

\[
\log\sigma(u_w^\top v_c)+\sum_{k=1}^{K}\log\sigma(-u_w^\top v_{n_k}).
\]

复杂度约 \(O(Kd)\)。它非常适合学习表示，但输出不是规范化的完整词表概率。

**层次 softmax**把词表叶子组织成二叉树，预测一个词转为沿根到叶路径做约 \(\log V\) 次二分类。它给出归一化概率，但效果和速度受树结构影响；高频词可放在较短路径。

**sampled softmax**保留多分类思想，只取真实类和采样子集近似 softmax，并用采样概率修正 logit/梯度偏差。它目标更接近 full softmax，但近似质量依赖样本数和 proposal distribution；实现不当会产生有偏梯度。

## 工程取舍

负样本不能只均匀抽取：太容易的样本梯度接近零，太难或假负样本会伤害语义。Word2Vec 常对词频分布做平滑；现代对比学习常用批内负样本，但会受 batch 构成影响。分布式训练扩大负样本池时，需要考虑跨卡 all-gather 和重复正例。

对自回归 LLM，full softmax 提供精确下一个 token 似然和统一生成分布，通常仍是主流；采样方案更常见于极大词表、推荐和表示学习。训练时用近似、推理时换 full softmax，概率校准可能改变，需单独评估。

面试回答应明确复杂度从 \(V\) 降到 \(K\) 或 \(\log V\)，并指出负采样不是 softmax 的简单加速实现，而是不同判别目标；sampled softmax 才更直接近似词表归一化。
