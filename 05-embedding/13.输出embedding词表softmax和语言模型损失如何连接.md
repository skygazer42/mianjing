# 13. 输出 embedding、词表 softmax 和语言模型损失如何连接？

## 计算链路

对位置 \(t\) 的隐藏状态 \(h_t\in\mathbb{R}^d\)，输出权重 \(W\in\mathbb{R}^{V\times d}\) 产生 logits：

\[
z_{t,j}=h_t^\top W_j+b_j,\qquad
p(y=j\mid h_t)=\frac{e^{z_{t,j}}}{\sum_k e^{z_{t,k}}}.
\]

真实下一个 token 为 \(y_t\) 时，交叉熵是 \(\mathcal L_t=-\log p(y_t\mid h_t)\)。从几何上看，\(W_j\) 是类别 \(j\) 的输出向量；隐藏状态与某行点积越大，该 token 越可能被预测。输入输出共享时 \(W=E\)，输出类别原型就是输入 embedding 行。

## 梯度揭示了什么

\[
\frac{\partial\mathcal L_t}{\partial z_{t,j}}
=p_j-\mathbf1[j=y_t].
\]

正确 token 的 logit 被向上推，其他 token 按当前概率被向下推。进一步有

\[
\frac{\partial\mathcal L_t}{\partial W_j}
=(p_j-\mathbf1[j=y_t])h_t.
\]

这说明 full softmax 即使标签只有一个，也会更新整个输出词表；高概率错误类别获得更强负梯度。label smoothing 会把 one-hot 目标改成软分布，降低过度自信，但也改变最优概率和校准。

## 数值与工程

实现交叉熵应使用 log-sum-exp 技巧，先减去最大 logit，避免 FP16/BF16 指数溢出；通常使用融合 linear + cross-entropy 内核，避免显式保留巨大的 \([B,L,V]\) 中间张量。词表并行时每个设备只存部分 \(W\)，但 softmax 分母和目标 logit 需要跨设备归约。训练阶段 sampled softmax/负采样可近似降低成本，却不再是精确词表似然。

输出 bias \(b_j\) 容易学习词频先验；去掉 bias 或共享权重不等于输出概率只由语义相似度决定，因为隐藏状态由深层网络针对预测任务塑造。生成时 temperature、top-k/top-p 作用于 logits/概率采样，不会改变已经训练好的输出 embedding。

面试回答应从形状、logit、softmax、交叉熵一路写到 \(p-y\) 梯度，并指出大词表的计算/内存瓶颈及稳定 softmax。这样比只说“embedding 后接全连接层”更完整。
