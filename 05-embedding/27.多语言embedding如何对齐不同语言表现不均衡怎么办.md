# 27. 多语言 embedding 如何对齐，不同语言表现不均衡怎么办？

## 对齐目标

多语言 embedding 希望语义等价的跨语言文本落在同一空间，同时保留每种语言内部的区分结构。可用平行句对做跨语言对比学习：翻译对为正例，批内其他句为负例；也可从强单语/多语 teacher 蒸馏相似度，使学生在多语言输入上复现统一几何。共享 Transformer 与子词词表提供参数共享，但并不自动保证对齐。

## 不均衡来源

高资源语言语料和负样本远多于低资源语言，优化会偏向前者；同一 tokenizer 对不同文字的 token 膨胀率不同，低资源语言更易被截断；翻译数据可能只覆盖正式文体，方言、混合语言和专有名词欠缺。批内负样本还可能利用“语言身份”走捷径：模型先区分语种，而非学习语义。

## 改进方法

按语言温度采样或上采样低资源语种，防止高资源语言完全主导；每批混合跨语言正对与同语言 hard negatives，使模型既学对齐又学细粒度区分。加入多向翻译、回译和代码混合数据，但要过滤机器翻译伪影。可使用语言均衡 loss 权重或按语言动态调整，必要时为特殊文字保留适配器，同时通过蒸馏保持公共空间。

如果 tokenizer 导致某语言平均 token 数过高，应先量化 truncation rate 和 token/character 比；有时扩充词表并继续预训练比单纯重采样更有效，但会引入词表与 checkpoint 迁移成本。

## 评估

不要只汇总一个多语平均分。建立 language × language 检索矩阵，分别测 A→B、B→A、单语和跨语 Recall@K；按资源量、文本长度、书写系统和代码混合切片。检查各语言向量范数、均值、hubness 和相似度阈值差异。若只在英译测试集上评估，可能高估自然本地文本效果。

面试回答应说明“共享参数不是对齐保证”，并从平行对比目标、均衡采样、tokenizer 覆盖和矩阵化评估四方面回答。最终是否使用统一阈值，也应依据各语言校准曲线决定。
