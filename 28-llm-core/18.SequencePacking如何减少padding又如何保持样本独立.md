# 18. Sequence Packing 如何减少 padding，又如何保持样本独立？

    ## 结论先行

    Sequence packing 把多个短样本拼进固定长度 block，提高 token 利用率；关键是同时维护 position、segment/document id、loss mask 与 attention mask，不能把简单 concat 当作完成。面试中需区分“只是把 token 放在一起”和“模型不会跨样本注意”的差别。实验把六段客服对话 token 按 10 token block 贪心拼接，比较普通 padding 槽位、packing 利用率和 segment id；随后展示漏 segment mask 后跨文档 attention 泄漏。

    ## 公式与具体例子

    packing 后 mask 应满足 $M_{ij}=1$ 当且仅当 $j\le i$ 且 $s_i=s_j$；position 可在每段重置或连续，必须与训练/推理约定一致。

    对应 Notebook 使用“支付退款、登录验证码、陌生转账、地址修改、盗刷冻结、发票更正”六条脱敏客服事件，先给出同口径 baseline，再打印核心实现的中间量、结果表和可复现失败。受控小数据只用于讲清机制，不可外推为生产收益。

    ## 工程取舍

    生产实现要处理 EOS、截断、FIM、多轮 label mask 和跨 rank 数据重排；错误 mask 会造成训练泄漏且很难从总 loss 发现。

    ## 常见坑

    只生成 packed token 不生成 segment id，或对每段重置 position 却没有在推理/rope scaling 中保持一致。
